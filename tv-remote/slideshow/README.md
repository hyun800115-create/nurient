# 우리들의 안전 앨범 (사진 슬라이드 영상)

돌잔치 영상처럼 사진이 폴라로이드에 담겨 한 장씩 넘어가는 1분짜리 안전 영상이에요.
사진마다 안전 문구, 손글씨 메모, 회사 로고가 들어가고 음악이 깔려요.

- 완성 영상: `out/safety-album-portrait.mp4`(세로, 휴대폰용), `out/safety-album-landscape.mp4`(가로, TV·회의용)
- 사진은 Blender로 만든 3D 장면이에요.

실제 직원 사진을 쓸 때는 찍힌 분들의 동의를 받아 주세요.

## 다시 만들기

```bash
# 글꼴 (Jua, Nanum Pen Script, Noto Sans KR) 받기: fonts/ 폴더에 풀기
for p in jua nanum-pen-script noto-sans-kr; do npm pack @fontsource/$p; done
# tv-remote 폴더를 웹서버로 열고, 브라우저에서 slideshow/index.html 재생 (가로는 ?landscape)
python3 -m http.server 8777
```

영상 파일은 Playwright로 프레임을 저장한 뒤 ffmpeg로 합쳐서 만들어요.
