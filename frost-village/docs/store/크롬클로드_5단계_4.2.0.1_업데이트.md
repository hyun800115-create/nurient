# 크롬 Claude 5단계 — 고침 버전 4.2.0.1 올리기

크롬 Claude에게 붙여 넣는 네 번째 부탁 글이에요. 고침 버전 **4.2.0.1 (버전 코드 4023)** 을 아래 두 트랙에 올려요.
- **내부 테스트**: 대표님 폰에서 바로 업데이트해 보는 용도
- **비공개 테스트**: 아직 검토에 보내지 않은 4.2.0 (4022) 대신 4.2.0.1로 바꿔요

## 이번 버전에서 고친 것

- **유령 물건:** 다 쓴 생선·고기·코인이 화면에 남아 보이던 것을 고쳤어요. 화덕 구이도 이제 제대로 쌓여요.
- **소리:** 홈 버튼, 다른 앱으로 이동, 뒤로 가기, 잠금 화면에서 게임 소리가 바로 멈춰요. 첫 화면 음악은 누르지 않아도 나와요.
- **주민 끼임:** 주민이 물건, 벽, 울타리, 소품, 광산 바위 틈에 끼어 멈추던 것을 고쳤어요.
- **돈 내는 발판:** 건물 뒤나 물건 더미, 손님 줄에 가려지지 않게 잘 보이는 자리로 옮겼어요.
- **손가락 튜토리얼:** 새로 시작한 사람에게 손가락이 하나씩 알려 줘요. 건너뛸 수 있고, 설정 › 놀이에서 다시 볼 수 있어요.
- **화면 버전 표시:** v4.2.0.1

### 소리 점검 8가지

1. 게임 중 홈 버튼을 누르면 소리가 바로 꺼지나요? 게임 아이콘을 다시 누르면 소리가 이어서 나오나요?
2. 최근 앱 화면에서 문자 앱으로 갔다가 다시 게임으로 돌아와 보세요.
3. 화면을 껐다가 다시 켜고 잠금을 풀어 보세요. 잠금 화면에서는 조용하고, 잠금을 풀면 소리가 나와야 해요.
4. 뒤로 가기 → 「계속하기」, 그리고 뒤로 가기 → 「끝내기」를 해 보세요. 음악이 바로 꺼지는지, 다시 열었을 때 마을이 그대로인지 봐 주세요.
5. 게임 중에 전화 받기, 알람 울리기, 카카오톡 보이스톡 받기를 해 보세요.
6. 화면 분할로 게임과 다른 앱을 같이 띄워 보세요.
7. 멜론 같은 음악 앱을 틀어 둔 채 게임을 열어 보세요. 게임 설정의 음악을 켠 상태와 끈 상태 둘 다 해 주세요.
   - 게임 음악이 켜져 있으면 음악 앱이 잠시 멈춰요. 이건 대표님이 고른 방식이에요.
   - 게임 음악이 꺼져 있으면 음악 앱이 계속 나와야 해요.
8. (가능하면 다른 폰에서) 앱을 새로 설치해 처음 열 때, 화면을 누르지 않아도 인트로 음악이 나오는지 확인해 주세요.
