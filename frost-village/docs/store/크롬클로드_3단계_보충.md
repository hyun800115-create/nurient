# 크롬 Claude 3단계 보충 — 남은 앱 콘텐츠 4개 + 개인정보처리방침 주소 바꾸기

크롬 Claude가 1단계를 마친 뒤 남긴 일(콘텐츠 등급, 타겟층, 데이터 보안, 광고 ID, 테스터 의견 이메일)과
개인정보처리방침 주소를 Google 문서 「웹에 게시」 주소(…/pub)로 바꾸는 일을 한 번에 부탁하는 글이에요.
답의 근거는 `console_answers_ko.md`와 같아요.

**왜 주소를 바꾸나요?** 지금 주소는 Google 문서 `/edit` 링크예요. Play 심사는 "수정 화면이 아닌 일반 웹페이지"를
원해서 `/edit` 링크가 반려될 때가 있어요. 「웹에 게시」 주소는 로그인 없이 읽기만 되는 깨끗한 페이지라 안전해요.

## 크롬 Claude에게 붙여 넣을 글

~~~text
좋아, 이어서 진행해 줘. 지켜야 할 것은 그대로야: 「검토를 위해 보내기」, 「출시」, 「변경사항 게시」 버튼, 약관·동의 체크,
콘텐츠 등급의 마지막 「제출」, 파일 고르기는 내가 직접 해. 아래에 없는 질문이 나오면 추측하지 말고 멈춰서 물어봐.

1) 개인정보처리방침 주소를 「웹에 게시」 주소로 바꾸기
 - 새 탭에서 이 Google 문서를 열어: https://docs.google.com/document/d/1BY8OzERdhUoriP3AAP5-owHMW1Gx-BXUc-xwNoMfDlw/edit
 - 「파일」 → 「공유」 → 「웹에 게시」 → 「링크」 → 「게시」. "게시하시겠습니까?" 확인 창이 뜨면
   나에게 "확인을 눌러 주세요"라고 말하고 기다려.
 - 나온 주소(…/pub 으로 끝나는 주소)를 새 탭에서 열어 로그인 없이 방침 글이 보이는지 확인해.
 - Play Console 「앱 콘텐츠」 → 「개인정보처리방침」의 주소를 그 /pub 주소로 바꾸고 「저장」.

2) 광고 ID
 - "앱에서 광고 ID를 사용하나요?" → 「아니요」 → 「저장」.
   (이 게임의 권한은 진동(VIBRATE)과 인터넷(INTERNET) 두 개뿐이고 광고 ID(AD_ID) 권한은 없어.)

3) 데이터 보안
 - 개요 화면은 「다음」.
 - "앱이 필수 사용자 데이터 유형을 수집하거나 공유하나요?" → 「아니요」.
   (게임 저장과 주민과 나눈 이야기는 휴대폰 안에만 있고 밖으로 보내지 않아.)
 - 혹시 더 물으면: 계정 만들기 → 아니요, 데이터 종류 목록 → 아무것도 체크하지 마.
 - 요약에 "데이터 수집 안 함 · 공유 안 함"처럼 보이면 「저장」.

4) 타겟층 및 콘텐츠
 - 타겟 연령: 「13~15세」, 「16~17세」, 「18세 이상」 세 개만 체크해. 12세 이하는 체크하지 마.
 - "앱이 의도치 않게 아동의 관심을 끌 수 있나요?" → 「예」. 이유 칸이 있으면:
   "귀여운 그림체의 마을 게임이지만 13세 이상을 대상으로 합니다. 광고, 결제, 데이터 수집, 다른 사용자와의 소통이 없습니다."
 - 가족 정책·Teacher Approved 프로그램 참여를 묻으면 참여하지 말고 나에게 말해 줘. 요약까지 가서 「저장」.

5) 콘텐츠 등급 (IARC 설문)
 - 이메일: nurient.help@gmail.com, 카테고리: 「게임」. 이용약관 동의 체크가 나오면 나에게 체크해 달라고 말하고 기다려.
 - 아래는 모두 「아니요」: 폭력·피·무기, 공포, 성적 내용·노출, 욕설·저속한 유머, 술·담배·약물,
   도박·도박 흉내·랜덤 보상 구매(뽑기·전리품 상자), 사용자끼리 소통하거나 콘텐츠를 주고받는 기능, 위치 공유,
   디지털 상품 구매(인앱 결제), 제한 없는 인터넷 접근(웹 브라우저·검색), 생성형 AI.
   (주민들이 장난으로 눈싸움하는 정도만 있어. "가벼운 만화적 표현도 포함"이라고 따로 물어서 「아니요」가 어색하면
   멈추고 물어봐. 게임 속 주민과 이야기하는 기능은 다른 사람과 연결되지 않는 오프라인 기능이고 AI가 아니야.)
 - 「저장」 → 「다음」으로 요약 화면까지 가서 결과(예상: 전체이용가 근처)를 읽어 주고 멈춰. 「제출」은 내가 눌러.

6) 비공개 테스트 「눈꽃마을 비공개 테스트」 → 「테스터」 탭 → 「의견 URL 또는 이메일 주소」에
   nurient.help@gmail.com 을 넣고 「저장」.

7) 끝나면 정리해 줘: 앱 콘텐츠 항목별 완료(초록 체크) 여부, 새 개인정보처리방침 주소(/pub), 내가 눌러야 하는 것,
   남은 경고. 「게시 개요」에 쌓인 변경사항은 읽어만 주고 보내지 마.
~~~
