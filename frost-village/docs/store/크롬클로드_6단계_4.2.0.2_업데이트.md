# 크롬 Claude 6단계 — 버전 4.2.0.2 올리기

크롬 Claude에게 붙여 넣는 다섯 번째 부탁 글이에요. 버전 **4.2.0.2 (버전 코드 4024)** 를 올려요.
- **비공개 테스트** (먼저): 지금 테스터들에게 나가 있는 4.2.0.1 (4023) 위에 새 버전으로 올려요.
  테스터 폰에는 플레이 스토어 「업데이트」로 들어가고, 마을은 그대로 남아요.
- **내부 테스트** (이어서): 같은 파일을 라이브러리에서 골라 대표님 폰에도 올려요.

새 버전을 올려도 「테스터 12명 · 14일」 기간은 처음부터 다시 세지 않아요.

## 이번 버전에서 바뀐 것

- **1단 노점 새 단장:** 빨간 천막 대신 「눈꽃 노점」 간판을 달고, 계산대를 낮췄어요.
  점원은 앞치마와 모자를 쓴 어른이고, 작은 발판 위에 서서 손님을 봐요.
- **점원 고용 발판:** 이름표 그림이 새 점원 얼굴로 바뀌었어요.
- **진열대:** 음식 탑이 간판을 가리지 않아요. 빵처럼 보이던 바구니는 천, 빈 바구니, 숟가락 통으로 바꿨어요.
- **유령 재료:** 건물이 다 지어진 뒤에 날아오던 재료가 땅에 남아 보이던 문제를 고쳤어요.
- **화면 버전 표시:** v4.2.0.2

## 시작하기 전에 (대표님)

1. 받은 게임 파일 **`snowbloom-4.2.0.2.aab`** 를 컴퓨터의 찾기 쉬운 곳(예: 다운로드 폴더)에 두세요.
2. 크롬에서 Play Console(https://play.google.com/console)을 열어 두세요.
3. 아래 `~~~` 상자 안의 글을 **전부** 복사해서 크롬 Claude에게 붙여 넣으세요.
4. 파일 고르기 창이 뜨면 대표님이 `snowbloom-4.2.0.2.aab` 를 골라 주세요.
5. 마지막 「출시」, 「저장 및 게시」, 「검토를 위해 보내기」 버튼은 대표님이 직접 눌러 주세요.

## 직접 하실 때 (크롬 Claude 없이)

1. https://play.google.com/console → 「행복한 눈꽃마을 이야기」
2. 왼쪽 「테스트 및 출시」 → 「테스트」 → 「비공개 테스트」 → 「눈꽃마을 비공개 테스트」 → 「트랙 관리」
3. 「새 버전 만들기」 → `snowbloom-4.2.0.2.aab` 업로드 → 버전 코드 4024 확인
4. 출시 이름 `4.2.0.2 (4024)`, 출시 노트는 위 [출시 노트] 복사
5. 「다음」 → 「저장」 → 「게시 개요」에서 「검토를 위해 변경사항 제출」
6. 내부 테스트도 「새 버전 만들기」 → 「라이브러리에서 추가」 → 4024
