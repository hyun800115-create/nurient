# Play Console 답변 모음 — 행복한 눈꽃마을 이야기

Play Console → **정책 및 프로그램 → 앱 콘텐츠**(App content)에 있는 설문들의 답이에요. 답마다 왜 그렇게 답하는지,
코드에서 어디를 확인했는지 적었어요. 기준은 지금 휴대폰에 깔린 **v4.2 앱**(게임 코드 커밋 `aa169bd`, 테스트 APK
`snowbloom-v4.2-final.apk`)이에요. Play에 올릴 빌드(AAB)는 이 게임 코드를 그대로 담고, 껍데기(안드로이드 쪽)만
Play 규칙에 맞게 바뀌어요.

> **중요:** 나중에 게임이 정보를 다루는 방식이 바뀌면(구글 로그인, 클라우드 저장, 온라인 AI 수다, 광고, 분석, 결제),
> 그 업데이트를 올리기 **전에** 아래 답과 개인정보처리방침을 먼저 고쳐야 해요. → 맨 아래 「나중에 바꿔야 할 것」.

Play Console 화면의 질문 문구는 가끔 바뀌어요. 문구가 조금 달라도 같은 뜻의 질문에 아래 답을 쓰면 돼요.

## 6. 타겟층 및 콘텐츠 (Target audience)

**추천: 13~15세, 16~17세, 18세 이상** (13세 미만은 선택하지 않기)

| 이유 | |
|---|---|
| 앞으로의 업데이트 | 구글 로그인·클라우드 저장·온라인 AI 수다를 계획하고 있어요. 13세 미만이 타겟에 들어가면 이런 기능이 모두 Google Play **가족 정책(Families Policy)** 과 아동 개인정보 법(미국 COPPA, 한국 만 14세 미만 법정대리인 동의 등)을 따라야 해서 훨씬 까다로워져요. |
| 지금은 문제없음 | 지금 앱은 정보 수집·광고·SDK가 없어서, 나중에 13세 미만을 추가해도 큰 일은 없어요. 거꾸로 13세 미만을 먼저 넣었다가 빼는 것은 번거로워요. |

설정하면 「앱이 의도치 않게 아동의 관심을 끌 수 있나요?」 같은 질문이 나와요. 귀여운 그림체라서 아이들 눈길을 끌 수 있는 건 사실이니 **솔직하게** 답하세요(보통 "예"). 구글이 스토어 등록정보를 보고 아동 대상이라고 판단하면 가족 정책을 따르라고 하거나 표시를 붙일 수 있어요. 지금 앱은 가족 정책의 핵심(광고·데이터 수집·SDK 없음)을 이미 지키고 있어서 큰 문제는 아니에요.

**13세 미만(5세 이하 / 6~8세 / 9~12세)을 고르면 생기는 의무** (요약 — Play Console의 가족 정책 화면에서 최신 내용을 꼭 확인하세요):
- 아동이 볼 수 있는 모든 콘텐츠가 아동에게 적절해야 해요.
- 광고를 넣는다면 가족용으로 인증된 광고 SDK만, 맞춤형(관심 기반) 광고 금지.
- 아동에게서 광고 ID 등 기기 식별자를 수집하면 안 되고, 쓰는 SDK도 아동 대상 서비스에 허용된 것만.
- 데이터 보안 답변과 개인정보처리방침이 정확해야 하고, 아동 개인정보 법(COPPA, GDPR, 한국 개인정보 보호법)을 지켜야 해요.
- 생성형 AI 기능을 넣으면 아동에게 적절한 결과만 나오도록 하고, 앱 안에서 부적절한 결과를 신고하는 기능이 필요해요.
- 로그인·클라우드 저장을 넣을 때도 아동 정보 수집 규칙(보호자 동의 등)을 지켜야 해요.

## 나중에 바꿔야 할 것 — 구글 로그인 + 클라우드 저장이 들어올 때

그 업데이트를 **올리기 전에** 아래를 모두 고쳐야 해요. (온라인 AI 수다, 광고, 분석, 결제도 같은 방식이에요.)

**데이터 보안 설문** — "수집함"으로 바뀌어요:
| 데이터 | 수집 | 공유 | 목적 | 선택/필수 |
|---|---|---|---|---|
| 개인 정보 → 이메일 주소, 사용자 ID (구글 계정에서 받는 것), 이름(받는다면) | 예 | 아니요 (클라우드 업체는 "서비스 제공업체"라 공유가 아님) | 앱 기능, 계정 관리 | 로그인이 선택이면 "선택사항" |
| 앱 활동 → 기타 사용자 생성 콘텐츠 / 앱 내 작업 (클라우드에 올리는 게임 저장) | 예 | 아니요 | 앱 기능 | 〃 |
| (온라인 AI 수다를 켜면) 메시지 → 기타 인앱 메시지 | 예 | AI 업체에 보내면 처리 방식에 따라 | 앱 기능 | |
- 전송 중 암호화: 예 (HTTPS)
- 삭제 요청 방법: 반드시 제공. **계정을 만들 수 있는 앱은 앱 안과 웹 페이지 두 곳에서 계정·데이터 삭제를 요청할 수 있어야 해요** (Play의 계정 삭제 요건) → 삭제 안내 웹 주소가 필요해요.

**개인정보처리방침** — 1~6번을 다시 써야 해요: 수집 항목(구글 계정 이메일·ID, 게임 저장), 목적, 보관 기간과 파기 방법, 처리를 맡기는 업체(클라우드 서버 회사 이름과 나라 — 해외면 국외 이전 항목), 계정·데이터 삭제 방법, 만 14세 미만이 가입하면 법정대리인 동의 절차(또는 14세 미만 가입을 막는 방법). 시행일과 바뀐 내용을 알려야 해요.

**앱 액세스 권한** — 로그인 없이도 전부 할 수 있으면 그대로, 로그인이 꼭 필요한 기능이 생기면 심사용 테스트 계정 정보를 넣어야 해요.

**콘텐츠 등급** — 다른 사람과 주고받는 기능(친구, 순위, 선물, 채팅)이 생기면 "사용자 간 소통"을 "예"로 바꾸고 다시 받아요.

**타겟층** — 13세 미만을 넣었다면 가족 정책의 로그인·데이터 규칙을 다시 확인해요.

**앱 코드** — 그때 INTERNET 권한을 실제로 쓰게 되니 게임 안 설정 화면에 "개인정보처리방침" 링크와 계정 삭제 버튼을 넣어요.
