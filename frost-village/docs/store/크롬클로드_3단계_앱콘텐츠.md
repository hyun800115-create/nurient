# 크롬 Claude 3단계 — 앱 콘텐츠 설문 채우기

크롬 Claude에게 붙여 넣는 두 번째 부탁 글이에요. Play Console의 **앱 콘텐츠**(개인정보처리방침, 앱 액세스 권한, 광고,
광고 ID, 콘텐츠 등급, 타겟층, 데이터 보안, 정부·금융·건강·뉴스 앱 선언)를 `console_answers_ko.md`의 답대로 채워요.
답마다 **왜 그렇게 답하는지와 코드 근거**는 `console_answers_ko.md`에 있어요. 이 글은 그 답을 크롬 Claude가 화면에서
고를 수 있게 짧게 옮긴 것이에요. 둘이 다르면 `console_answers_ko.md`가 맞아요(알려 주시면 고칠게요).

## 시작하기 전에 (디자이너님)

1. 2단계(`크롬클로드_2단계_스토어등록정보.md`)를 마쳤으면 좋아요(순서가 꼭 필요하진 않아요).
2. 크롬에서 Play Console에 로그인해 두세요.
3. 아래 부탁 글의 빈칸 두 개를 채운 뒤 붙여 넣으세요.
   - **개인정보처리방침 URL** (`[개인정보처리방침 URL 시작]` 아래 `＿＿＿＿`): 방침 페이지를 인터넷에 올린 뒤의 주소
     (→ `플레이스토어_등록안내.md` 5단계). **아직 주소가 없으면 그대로 두세요** — 크롬 Claude가 그 항목만 건너뛰어요.
   - **콘텐츠 등급 이메일** (`[등급 이메일 시작]` 아래 `＿＿＿＿`): 등급 인증서를 받을 이메일. 비워 두면 크롬
     Claude가 물어봐요.
4. 아래 상자(`~~~` 사이) 안의 글을 **전부** 복사해서 크롬 Claude에게 붙여 넣으세요.
5. 중간에 크롬 Claude가 **「제출」이나 약관 동의**를 디자이너님께 부탁할 거예요. 화면의 답을 한 번 훑어보고 직접 눌러 주세요.

## 크롬 Claude에게 붙여 넣을 글

~~~text
지금 열려 있는 크롬의 Google Play Console에서, 내 게임 「행복한 눈꽃마을 이야기」의 「앱 콘텐츠」 설문을 같이 채워 줘.
아래 [지켜야 할 것]을 먼저 읽고, [순서]대로 하나씩 해 줘. 화면 문구가 조금 달라도 같은 뜻의 질문에 아래 답을 쓰면 돼.
아래에 없는 질문이 나오거나, 답이 화면의 선택지와 맞지 않으면 추측하지 말고 멈춰서 나에게 물어봐.

[지켜야 할 것]
1. 절대 누르지 마: 「검토를 위해 보내기」, 「검토를 위해 변경사항 보내기」, 「변경사항 게시」, 「출시」, 「출시 시작」,
   「프로덕션으로 출시」, 「게시」, 「앱 삭제」. 「게시 개요」 화면에서도 아무것도 보내지 마. 내가 나중에 직접 할 거야.
2. 네가 누를 수 있는 것은 답 고르기, 「다음」, 「저장」, 「뒤로」뿐이야. 콘텐츠 등급의 마지막 「제출」(등급 제출)은
   요약 화면까지만 가서 나에게 "요약을 확인하고 제출을 눌러 주세요"라고 말하고 기다려.
3. 이런 화면이 나오면 바로 멈추고 나에게 말해: 비밀번호·로그인·2단계 인증, 결제·결제 프로필, 신원 확인(신분증·주소),
   약관·정책·법적 선언에 동의하는 체크나 버튼(예: "IARC 이용약관에 동의", "정보가 정확함을 확인"). 그런 체크는 내가 직접 해.
4. 「앱 콘텐츠」 안의 아래 항목만 고쳐. 스토어 등록정보, 앱 무결성, 앱 서명, 테스트, 출시, 가격, 국가는 건드리지 마.
5. 이미 답이 저장된 항목은 아래 답과 같으면 그대로 두고, 다르면 나에게 먼저 물어봐.

[순서]
0) 왼쪽 메뉴에서 「모든 앱」 → 「행복한 눈꽃마을 이야기」 → 「정책 및 프로그램」(또는 「모니터링 및 개선 → 정책 및 프로그램」)
   → 「앱 콘텐츠」로 가. 항목 목록(「선언해야 할 항목」 같은 이름)이 보이면 아래 순서대로 하나씩 「시작」 또는 「관리」를 눌러.

1) 개인정보처리방침
[개인정보처리방침 URL 시작]
https://docs.google.com/document/d/1BY8OzERdhUoriP3AAP5-owHMW1Gx-BXUc-xwNoMfDlw/edit?usp=sharing
[개인정보처리방침 URL 끝]
   - 위 줄이 ＿＿＿＿ 그대로이거나 비어 있으면: 이 항목은 건너뛰고 끝에 "개인정보처리방침은 주소가 없어 건너뜀"이라고 알려 줘.
   - 주소가 있으면: 개인정보처리방침 URL 칸에 그 주소를 그대로 넣고 「저장」.

2) 앱 액세스 권한
   - 「모든 기능을 특별한 액세스 권한 없이 사용할 수 있음」(로그인·회원가입·구독·지역 제한 없음)을 고르고 「저장」.
   - 심사용 계정·안내를 넣는 칸은 비워 둬(필요 없어).

3) 광고
   - "앱에 광고가 포함되어 있나요?" → 「아니요, 앱에 광고가 없습니다」 → 「저장」.

4) 광고 ID (목록에 있으면)
   - "앱에서 광고 ID를 사용하나요?" → 「아니요」 → 「저장」.

5) 콘텐츠 등급 (IARC 설문)
   - 「새 설문지 시작」(또는 「설문지 시작」).
   - 이메일 주소:
[등급 이메일 시작]
nurient.help@gmail.com
[등급 이메일 끝]
     (위 줄이 ＿＿＿＿ 그대로이거나 비어 있으면 멈추고 나에게 이메일을 물어봐.)
   - 카테고리: 「게임」.
   - 이용약관 동의 체크가 있으면 나에게 체크해 달라고 말하고 기다려.
   - 질문별 답 (같은 뜻의 질문에 이 답):
     · 폭력(만화·현실적 폭력, 피, 무기 등) → 아니요.
       (주민들이 장난으로 눈싸움만 해요. 질문이 "가벼운 만화적 표현도 포함"이라고 따로 묻고 "아니요"가 어색하면 멈추고 나에게 물어봐.)
     · 공포·무서운 요소 → 아니요.
     · 성적 내용·노출 → 아니요.
     · 욕설·비속어·저속한 유머 → 아니요.
     · 술·담배·약물(규제 약물) → 아니요.
     · 도박, 실제 돈 도박, 도박 흉내(시뮬레이션 도박), 랜덤 보상 구매(뽑기·전리품 상자) → 모두 아니요.
     · 사용자끼리 소통하거나 콘텐츠를 주고받는 기능(채팅, 사진 공유 등) → 아니요.
       (게임 속 주민과 이야기하는 기능은 다른 사람과 연결되지 않는 오프라인 기능이야.)
     · 사용자 위치를 다른 사용자와 공유 → 아니요.
     · 디지털 상품 구매(인앱 결제) → 아니요.
     · 제한 없는 인터넷 접근(웹 브라우저, 검색 엔진) → 아니요.
     · 생성형 AI 기능을 묻는 질문이 있으면 → 아니요.
     · 그 밖의 질문(예: 차별, 범죄 묘사, 공포 이미지 등) → 아니요. 위에 없는 질문이 "예"일 것 같으면 멈추고 나에게 물어봐.
   - 「저장」 → 「다음」으로 요약 화면까지 가. 예상 결과는 전체이용가(한국 GRAC 전체이용가, IARC 3+, PEGI 3, ESRB Everyone 근처).
     결과를 읽어 주고, 나에게 "요약을 확인하고 제출을 눌러 주세요"라고 말하고 기다려. 「제출」은 내가 눌러.

6) 타겟층 및 콘텐츠
   - 타겟 연령: 「13~15세」, 「16~17세」, 「18세 이상」 세 개만 체크해. 13세 미만(5세 이하, 6~8세, 9~12세)은 체크하지 마.
   - "앱이 의도치 않게 아동의 관심을 끌 수 있나요?" 같은 질문 → 「예」.
     (귀여운 그림체라 아이들 눈길을 끌 수 있어서 솔직하게 답해. 이유를 적는 칸이 있으면:
     "귀여운 그림체의 마을 게임이지만 13세 이상을 대상으로 합니다. 광고, 결제, 데이터 수집, 다른 사용자와의 소통이 없습니다.")
   - 「다음」을 눌러 가며 요약까지 가서 「저장」. 가족 정책·Teacher Approved 프로그램 참여를 묻는 화면이 나오면 참여하지 말고 나에게 말해 줘.

7) 데이터 보안
   - 개요 화면은 「다음」.
   - "앱이 필수 사용자 데이터 유형을 수집하거나 공유하나요?" → 「아니요」.
     (게임 저장과 주민과 나눈 이야기는 휴대폰 안에만 있고 밖으로 보내지 않아.)
   - "아니요"를 고르면 암호화·데이터 종류 질문은 보통 나오지 않아. 혹시 나오면:
     · 사용자가 앱에서 계정을 만들 수 있나요 → 아니요(계정·로그인 없음).
     · 데이터 삭제 요청 방법 → 해당 없음 / 수집하지 않음.
     · 독립적인 보안 검토 → 아니요(받지 않음) 또는 건너뛰기.
     · 데이터 종류 목록(위치, 개인 정보, 금융, 건강, 메시지, 사진·동영상, 오디오, 파일, 캘린더, 연락처, 앱 활동,
       웹 브라우징, 앱 정보 및 성능, 기기 ID)은 아무것도 체크하지 마.
   - 요약 화면에 "데이터 수집 안 함 · 제3자와 공유 안 함"처럼 보이면 「저장」.

8) 그 밖의 선언 (목록에 있는 것만)
   - 정부 앱 → 「아니요」.
   - 금융 기능 → 「이 앱에는 금융 기능이 없음」. (게임 속 「서리 은행」은 게임 코인만 다루는 건물이야.)
   - 건강 앱 / 건강 기능 → 「아니요」 또는 「건강 기능 없음」.
   - 뉴스 앱 → 「아니요」. (게임 속 "마을 소식"은 게임 이야기야.)
   - 코로나19 접촉 추적·상태 앱 → 「아니요」.
   - 위에 없는 선언(예: 사진·동영상 권한, 전면 인텐트, 포그라운드 서비스, 접근성 API)이 나오면 답하지 말고 나에게 말해 줘.
     이 게임의 권한은 진동(VIBRATE)과 인터넷(INTERNET) 두 가지뿐이야.

9) 끝나면 「앱 콘텐츠」 목록으로 돌아가서 정리해 줘: 항목마다 완료(초록 체크)인지, 건너뛴 것(개인정보처리방침 등),
   내가 직접 눌러야 하는 것(등급 제출), 남은 경고. 「게시 개요」에 쌓인 변경사항은 읽어만 주고 보내지 마.
~~~

## 끝나면 (디자이너님)

- 콘텐츠 등급 요약을 확인하고 **「제출」은 직접** 눌러 주세요. 결과(전체이용가 근처)가 다르게 나오면 화면을 캡처해 보내 주세요.
- 개인정보처리방침 주소가 생기면 이 글의 1)번만 다시 붙여 넣어도 돼요(앱 콘텐츠 → 개인정보처리방침에 주소 넣고 저장).
  스토어 설정의 연락처에도 같은 주소를 넣을 수 있어요(선택).
- **「검토를 위해 보내기」는 아직 누르지 마세요.** 첫 AAB를 비공개 테스트에 올릴 때 한꺼번에 보내요 → `플레이스토어_등록안내.md`.
- 나중에 게임이 정보를 다루는 방식이 바뀌면(구글 로그인, 클라우드 저장, 온라인 AI 수다, 광고, 결제) 이 답들을 먼저
  고쳐야 해요 → `console_answers_ko.md` 맨 아래.
