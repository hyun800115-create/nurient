# 서리마을 v5~v8 개발 계획 (대표님용 쉬운 정리)

> 이 문서는 개발자용 확정 계획 `docs/v5_v8_plan.md` 를 쉬운 말로 옮긴 거예요.
> 두 가지 제안서(재미 쪽 / 기술 쪽)를 비교해서 더 좋은 쪽을 골랐고, 서로의 좋은 생각은 합쳤어요.

## 2. 등급과 승격 조건

### 3.3 탈것의 시대

| 시대 | 탈것 | 하는 일 |
|---|---|---|
| 읍 | 말썰매 버스 (말 두 마리, 8자리, 마부 아저씨) | 이웃을 우리 광장으로. 추운 날 말 입김이 폴폴 |
| 읍 | 증기 짐차 | 화물장 → 역 → 이웃 가게 선반으로 물건이 휙휙 |
| 읍 | 개썰매 | 촌장님 편지 배달 경주 |
| 읍 | 짐수레 썰매 | 역 짐꾼이 더 많이 날라요 |
| 도시 | 레트로 버스 · 운송트럭 · 자동차 (동글동글) | 버스 노선, 물건 운반, 주민 차 (부자 집 앞에 주차) |
| 도시 | **촌장 트럭** | 촌장님이 직접 운전하는 배달 미션 ("빵빵" 버튼) |
| v8 | 경찰차 · 소방차 · 구급차 · 배달 밴 · 이삿짐 트럭 · 굴착기 · 덤프트럭 | 사건, 물류, 이사, 다시 짓기 |

- 차는 사람 앞에서 꼭 멈춰요. **아무도 부딪히지 않아요.**
- 정류장에 서 있으면 "다음 버스 12초 · 어디로?" → 고르면 촌장님이 창가 자리에 앉아 손을 흔들며 가요. 기차도 똑같이 탈 수 있어요.

### 3.4 주민의 일생

| 단계 | 화면에서 | 촌장님이 하는 일 |
|---|---|---|
| 친구 · 단짝 | 반가운 인사, 나란히 걷기. 다퉜다가 다음 날 "어제는 미안했어" | 편지 전해 주기 |
| 연인 | 벤치에 나란히 앉기, 저녁 산책, 하트 | 몰래 꽃다발 전하기 |
| 청혼 | 분수·광장·등대·노을 해변에서 무릎 꿇기, 구경꾼 박수 | 결혼식 준비 미션 |
| **결혼식** | 마을회관 앞 카펫·아치·의자·케이크. 하객들이 **예쁜 옷으로 갈아입고** 와요. 꽃가루, 종소리, 신랑은 긴장해서 땀 삐질, 서약, 하트, 사진 플래시, 케이크에 붙은 아이들, 눈 속 첫 춤 | 음식·꽃·케이크 준비, **축사** |
| 기쁜 소식 | 집 앞에 흔들리는 요람 | — |
| **아기 탄생** | 저녁에 병원 → 새벽에 유모차를 밀며 나와요. 까르르 | **이름 고르기** (3개 중 하나, 또는 "부모님이 정할게요"), 선물 |
| 유모차 산책 → 걸음마 | 오후 산책, 4살에 걸음마 | — |
| **첫 등교** | 책가방이 생기고, 교문에서 한 번 뒤돌아봐요 | 같이 걸어가 주기 |
| 학교생활 | 종소리, 쉬는 시간 눈싸움, 맑은 날 **눈밭 야외 수업** | 학교 점심 빵 |
| 청소년 · 어른 | 카페, 첫 아르바이트, 일, 저금 | — |
| 노년 · **세 가지 소원** | "말썰매 버스 타고 분수 보고 싶어요", "등대 불빛 보고 싶구나", "따뜻한 바다에 발 담그고 싶어요" | 할머니를 모시고 버스·기차로 함께 가요 |
| **하늘나라 여행** (켜 둔 경우만) | 마지막 날 좋아하던 곳을 둘러보고 "촌장님, 그동안 고마웠어요". 다음 날 기억의 정원에서 흰 꽃으로 배웅. **콩이가 촌장님 옆에 앉아요.** 눈송이가 **하늘로** 올라가요 | 흰 꽃 놓기 |

**지켜요:**
- 아프다·죽는다 같은 말은 **절대 안 써요**. "하늘나라 여행", "배웅", "기억"만 써요.
- 아주 나이 많은 분만, 아주 가끔(게임 날 15일에 한 번 이하), 정원이 생긴 뒤에만, 그리고 v5 시작 3시간 뒤부터예요.
- 이름 있는 원래 주민(빵집 아주머니, 도윤이 등)은 나이도 안 먹고 떠나지도 않아요.
- 설정 **"생애 이벤트: 끄기"** → 노년까지만, 이별 없음 (기획서 그대로).
- 나이 속도: 아이는 게임 날 1.5일에 한 살, 어른은 4일에 한 살 → 아기가 약 1시간 45분 뒤 입학, 약 4시간 반 뒤 어른 ("한 번 플레이에 한 세대").

### 3.6 은행 (v5)

|---|---|
| 저금 | 창구에 서면 코인이 쏙. 게임 하루에 1% 이자 (새벽 6시). 5만까지 (v6부터 15만) |

### 3.7 신문과 주민 카드 (v5)

- **솔방울 신문**: 첫 결혼식 다음 날 아침에 창간. 매일 아침 7시에 신문 아이콘이 반짝 → 눌러서 읽어요 (게임은 안 멈춰요). 결혼, 아기, 새 가게, 배, (v8) 사건 소식.
- **주민 카드**: 이름, 나이, 직업, 집, 단짝, 배우자, 아이, 좋아하는 것, 촌장님에 대한 기억 + "수다 떨기".
- 주민들이 소문을 나누면 머리 위에 작은 **귀 아이콘**이 떠요.

## 4. v6 — 갈매기 항구

**어디에:** 솔방울 마을 동쪽, 기찻길 남쪽의 **따뜻한 바다(난류)** 가에요. 그림 속 항구 건물들이 모두 화면 왼쪽 아래(바다 쪽)를 보고 있어서, 바다가 그쪽에 있어야 배가 건물 **앞**에 예쁘게 보여요. 해변도 같은 바닷가, 등대 너머에 있어요.

**어떻게 열려요:** 도시가 된 뒤 멀리서 뱃고동과 갈매기 소리 → "갈매기 항구 방면" 표지판 조사 → **동쪽 철길 잇기** → 안개가 걷히며 **잠든 항구**가 보여요 (눈 덮인 역, 낡은 경매장, 꺼진 등대, 기둥 위 갈매기).

| 순서 | 짓는 것 | 비용 | 생기는 일 |
|---|---|---|---|
| 0 | 동쪽 철길 잇기 | 12,000 + 판자 80 + 주괴 40 | 항구 땅이 열려요 |
| 1 | 항구역 | 8,000 + 판자 40 + 주괴 20 | **바닷가 열차**가 다녀요 (지금 기차는 그대로) |
| 2 | 수산물 경매장 | 6,000 + 판자 30 | 종소리와 경매사 외침, 생선 1.5배 값 |

## 5. v7 — 햇살 해변

## 12. 만드는 순서

1. **지금 (v4 마무리하는 동안):** 공통 부품 → 이야기 · 미션과 은행 · 탈것 → 항구 · 해변 · 물류 · 사건. 각 부품은 **혼자 돌려 보는 시험 화면(랩)** 을 가져요. 대표님은 게임에 넣기 **전에** 그 화면 사진·움직이는 그림으로 먼저 보세요.
2. **v4가 끝나면:** 게임에 차례로 끼워요. v5 → v6 → v7 → v8. 버전마다 검사 → 고치기 → 확인 → 테스트 링크.
3. 이별 장면은 v5를 내기 전에 **대표님이 미리보기로 꼭 먼저 보시고** 결정해 주세요.

**숫자 고치는 곳:** 지금은 부품마다 `tuning.js` (한국어 설명 있음). 게임에 넣을 때 `balance.js` 의 `v5`~`v8` 칸으로 그대로 옮겨서, 대표님은 앞으로 `balance.js` 한 곳에서 고치시면 돼요. 미션은 `catalog.js`, 글자는 `strings.js`.
