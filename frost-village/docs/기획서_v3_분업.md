# 서리마을 v3 추가 기획 — 일꾼 분업 (대표님 아이디어)

> "처음엔 내가 굽고, 요리사를 따로 채용하면 그때부터 요리사가 굽는다.
> 생선을 화덕으로 옮기는 짐꾼과, 화덕에서 가게로 옮기는 짐꾼도 따로 있어야 한다."

## 1. 생산 라인 하나 = 다섯 명의 일
| 순서 | 일 | 처음 | 고용하면 |
|---|---|---|---|
| ① 채집 | 물고기 잡기 / 나무 베기 / 밀 베기 / 광석 캐기 / 사냥 | 촌장이 직접 | **채집 일꾼**(어부·나무꾼·농부·광부·사냥꾼)이 잡아서 **모아두는 곳**(그물·통나무 더미·밀 더미·광석 더미·고기 걸이)에 쌓음 |
| ② 재료 운반 | 모아두는 곳 → 가공소 입구 | 촌장이 직접 날라요 | **재료 짐꾼**이 길을 따라 날라요 |
| ③ 가공 | 굽기 / 톱질 / 빵 굽기 / 제련 / 훈제 | **촌장이 가공소 작업 자리에 서 있어야** 가공돼요 | **가공 기술자**(요리사·제재공·제빵사·제련공·훈제사)가 자리를 지키며 자동으로 가공 |
| ④ 상품 운반 | 가공소 출구 → 가게 진열대 | 촌장이 직접 날라요 | **상품 짐꾼**이 길을 따라 날라요 |
| ⑤ 판매 | 계산대 | 촌장이 계산대에 서 있어야 계산 | **점원**이 자동 계산 |

→ 처음엔 촌장이 모든 일을 하느라 바쁘다가, 한 명씩 고용할수록 마을이 **스스로 굴러가는** 재미.

- 모아두는 곳에는 최대 40개까지 쌓여요 (`balance.js` → `labour.pileMax`). 꽉 차면 이름표가 깜빡이고, 일꾼은 땀 이모티콘을 띄우며 기다려요.
- 촌장은 모아두는 곳에서 직접 꺼내 갈 수 있고, 가공소 작업 자리(발판)에 서 있으면 들고 있던 재료가 바로 가공소로 들어가요.
- 기술자가 없을 때 촌장이 직접 가공하면 조금 더 빨라요 (`labour.chiefSpeed` = 1.25배). 기술자를 고용하면 촌장은 다른 일을 할 수 있어요.
- 두 번째·세 번째 일꾼은 같은 직업이라도 **다른 모습**으로 와요 (어부·나무꾼·농부·사냥꾼 b/c, 광부는 c — b 모습은 도구 장인 영감).

## 3. 고용 순서 (생선 라인 예시)
1. 촌장이 그물에서 생선을 모아 화덕에 넣고, **화덕 옆에 서서 굽고**, 판매대에 놓고, 계산대에서 계산
2. 점원 고용 (계산 자동)
3. 요리사 고용 (굽기 자동) → 촌장은 나르기만
4. 어부 고용 (물고기 자동으로 그물에 쌓임)
5. 생선 짐꾼 고용 (그물 → 화덕 자동)
6. 판매 짐꾼 고용 (화덕 → 판매대 자동) → **생선 라인 완전 자동!**
다른 라인도 같은 방식. 비용은 뒤로 갈수록 조금씩 올라가요 (`src/data/balance.js` 에서 조절).

- (v3.5 리뷰 수정) 같은 자리에 새 발판이 촌장 발밑에 생기면 화면 위에 "새 발판! 한 걸음 나왔다가 다시 올라서세요"가 뜨고 화살표가 발판 바로 옆을 가리켜요 (실수로 코인이 빠지지 않게 하는 규칙은 그대로).
- (v3.5 리뷰 수정) 어부를 고용한 뒤 화덕 출구에 구운 생선이 쌓여 있으면 화살표가 생선 통보다 **구운 생선 → 판매대**를 먼저 가리켜요. 손님이 주문을 일부만 받은 채 기다릴 때는 계산대가 아니라 생선을 더 구우러 가라고 알려 줘요.
- (v3.5 리뷰 수정) 작업 자리 발판은 계산대처럼 발자국 모양(서는 곳)이에요. 촌장은 일할 때 등을 돌리지 않고 앞쪽(SE)을 보며 일해요 (화덕·오븐·훈제장·통조림: 두 손으로 내려놓기, 제재소: 도끼질, 제련소·대장간: 망치질). 오븐 바로 앞 밀밭 칸 하나는 비워 두었어요 (`world.js` wheat.skip).
- 모아두는 곳은 낮고 넓게 쌓여요 (7줄, 6층까지만 보이고 그 위는 겹쳐 쌓임). 꽉 차고 촌장이 날라야 할 때만 이름표가 붉게 "가득!"으로 바뀌어 깜빡이고, 일꾼이 땀을 흘려요 (재료 짐꾼이 있거나 가공소가 꽉 차 있으면 조용히 기다림).
- 막힘 방지: 가공소에 재료가 있는데 아무도 일하지 않으면 화살표가 작업 자리를 가리킴. 가방이 꽉 찼는데 갈 곳이 없으면(어부 고용 전) 버리기 발판이 일찍 나타남. 모아두는 곳이 꽉 차면 이름표가 깜빡이고 화살표가 한 번 알려 줌. 돈이 충분하면 화살표가 코인 더미를 먼저 가리킴.

### 기존 저장 (v3 → v3.5)
- 진행은 절대 지워지지 않아요 (저장 v3 → v4 이전).
- v3에서 저절로 돌아가던 것은 그대로 저절로 돌아가요: 열린 구역의 가공소마다 **기술자**가 와 있고(화덕은 무언가 하나라도 해 둔 저장이면), 고용한 채집 일꾼의 라인에는 **재료 짐꾼**이 와 있어요. 지어 두었거나 짓던 대장간·통조림 공장에도 기술자가 따라와요.
- 모아두는 곳·강아지 친밀도는 새로 시작해요 (0).
