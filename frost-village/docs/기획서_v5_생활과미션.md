# 서리마을 v4~v5 추가 기획 — 탈것의 시대, 촌장 미션, 주민의 일생 (대표님 결정 정리)

## 대표님 결정
- 탈것: **② 시대가 발전하는 방식** — 마을 → 읍 → 도시로 커질수록 탈것과 길이 바뀜
- **촌장 미션**도 넣기 (운전 배달 등), 미션은 많을수록 좋고 **명성 포인트**를 받음
- 주민들은 **더 많은 이야기**를 나누고, 나눈 이야기를 **서로 기억**함
- 주민끼리 **사랑 → 결혼(마을회관 결혼식) → 아기 탄생 → 성장 → 노년 → 장례식**
- 놀이터·공원·학교·관공서 (이웃 마을 그림은 이미 완성)

## 1. 탈것의 시대 (마을 등급에 따라)
| 마을 등급 | 탈것 | 길 | 새 건물 |
|---|---|---|---|
| 마을 | 눈썰매, 개썰매, 짐수레 썰매 | 흙길·눈길 | — |
| 읍 | **말썰매 마을버스**, **증기 짐차** | 돌길 | 마구간 차고지, 썰매 정류장 |
| 도시 | **레트로 마을버스·운송트럭·자동차**(장난감 같은 동글한 모습) | 차선 있는 도로, 횡단보도, 인도 | 버스 차고지, 버스 정류장, 주차장, 주유소(겨울엔 연료 창고) |
- 운송트럭: 우리 마을 물건을 이웃 마을 가게로 한꺼번에 운반 (짐꾼은 마을 안, 트럭은 마을 사이)
- 마을버스: 이웃 마을 사람을 우리 마을로 태워 옴 → 노선·정류장이 늘수록 손님 증가
- 집 레벨이 오르면 집 앞에 자동차 (잘사는 마을의 표시)
- 길 업그레이드: 마을 등급이 오르면 길이 넓어지고 포장됨 (돌길 → 도로)

## 2. 촌장 미션과 명성
- **미션 게시판**(광장 게시판)과 주민들의 **부탁 말풍선**
- 미션 종류 (많을수록 좋게, 계속 새로 생김):
  - 부탁: "할머니에게 빵 5개 가져다주세요", "아이들 눈사람 만들기 도와주세요"
  - 배달 운전: 촌장이 **트럭을 직접 운전**해서 이웃 마을 가게에 물건 배달 (시간 안에!)
  - 행사: 결혼식 준비(케이크·꽃), 축제 준비, 새 주민 환영회
  - 생산 목표: "오늘 통조림 30개", "판자 50장 교역소에 납품"
  - 탐험: 망루 너머 새 땅 조사, 잃어버린 강아지 찾기
  - 일일·주간 미션, 연속 달성 보너스
- 보상: 코인 + **명성 포인트** → 촌장 칭호(새내기 촌장 → 존경받는 촌장 → 전설의 촌장), 특별 장식, 특별 건물, 주민 이사 증가

## 3. 주민의 일생 ("마을 이야기")
- 모든 주민은 이름·나이·성격·좋아하는 것·싫어하는 것·직업·집·가족이 있음
- **기억**: 함께 한 일(눈싸움, 대화, 선물, 촌장이 도와준 일)을 기억하고 나중에 대화에 꺼냄
  - 예) "어제 도윤이한테 눈덩이 맞았어! 오늘은 내가 이길 거야" / "촌장님이 빵 갖다주셔서 고마웠어요"
- **관계**: 친구 → 단짝 → 연인 → 결혼. 사이가 나빠지면 다투기도 함
- **결혼식**: 마을회관에서 하객이 모이고 음악·꽃가루, 촌장이 축사 (명성 +)
- **아기 탄생**: 결혼한 부부가 집이 있으면 아기가 태어남 (유모차 산책) → 아이 → 학교 → 어른
- **노년과 이별**: 오래 산 어르신만 평온하게 "하늘나라 여행"을 떠남 → **추모 정원**에서 꽃으로 배웅하는 장례식, 가족이 기억하며 이야기
  - 설정에서 **생애 이벤트 끄기** 가능 (끄면 노년까지만, 이별 없음)
- 시간: 하루(낮·저녁·밤)가 게임 시간 약 10분, 계절 변화. 나이는 천천히 들어서 한 번 플레이에 한 세대가 자라는 정도

## 4. 놀이와 공공시설
- 놀이터(그네·미끄럼틀·모래놀이), 공원(분수·벤치·산책), 학교(등교·수업 종·하교), 마을회관(결혼식·회의), 병원(아기 탄생), 추모 정원

## 5. 만드는 순서
1. v3.5 마무리 (분업, 강아지) → 테스트 링크
2. **v4**: 이웃 솔방울 마을 + 눈썰매 기차 + 주민 100명 일과 + 가게 창업·마을 성장 + 마을 등급(마을→읍) + **차가 다닐 수 있는 도로 구조**
3. **v5**: 탈것(말썰매 버스·증기 짐차 → 레트로 버스·트럭·자동차) + 차고지·정류장·주차장 + 촌장 운전 미션 + 미션 게시판·명성 + 주민 기억·관계·결혼·아기·노년·장례
4. 각 버전마다 검수 → 수정 → 확인 → 테스트 링크
