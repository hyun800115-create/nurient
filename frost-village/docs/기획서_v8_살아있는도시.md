# 서리마을 v8 기획 — 살아 있는 도시 (대표님 아이디어)

> "물류창고를 크게 하나 만들까? 안이 보이게, 각종 재료·식품·가공품·가구·공구·가전, 그 안에서 일하는 직원들,
> 오가는 물류차량, 상점들이 물건을 빨리 받고 정산받고… 그럼 은행도 있어야겠다. 주민들도 저축하고 대출받고.
> 주민들은 대화하고 기억하고, 새로운 것을 물어보고, 새 사람을 만나 사귀고, 이사 가고 이사 오고 —
> 수만 개의 이야기가 네트워크처럼. 마치 AI가 살아서 움직이는 도시.
> 경찰·소방관도 있고, 주민이 싸우거나 범죄를 저질러 잡히거나 현상수배, 불이 나면 소방차 출동,
> 불탄 건물을 철거하고 다시 공사해서 세우고."

## 1. 큰 물류센터 (안이 들여다보이는 건물)
- 촌장이 들어가거나 건물을 **누르면(PC는 마우스를 올리면) 지붕과 앞벽이 스르륵 투명**해지고 안이 보여요
- 안에는 **높은 선반**: 재료(통나무·판자·광석·주괴) / 식품(생선·빵·훈제고기·통조림) / **가구**(의자·식탁·소파·침대·옷장) / **공구** / **가전**(냉장고·난로·세탁기·라디오·텔레비전)
  - 선반 위 물건 높이 = 실제 재고 (많이 쌓이면 꽉 찬 선반)
- 일하는 사람들: 물건 고르는 직원, 포장 직원(컨베이어), **지게차 기사**, 사무실 정산 직원
- 앞마당: **트럭 하역장** — 운송트럭·배달 밴이 들어와 짐을 싣고 내려요
- **상점 주인들**이 와서 물건을 받아 가고 **정산**(장부에 도장 꽝) → 우리에게 돈
- 새 생산 사슬(2차→3차 산업): 판자 → **가구 공방** → 가구 / 주괴 → **가전 공장** → 가전 → 물류센터 → 가게·새 집으로

## 2. 은행
- 주민 저축(이자), 대출(가게 창업, 집 사기, 불탄 건물 다시 짓기) → **주민이 은행 대출로 가게를 열어요** (v4 가게 창업과 연결)
- 촌장도 이용: 돈을 맡기면 이자, 큰 공사 때 대출 / **화재 보험**
- 은행 안도 들여다보여요: 창구 직원, 번호표 대기, **금고 문**(빙글), 현금인출기

## 3. 진짜 살아 있는 것 같은 주민들 — "이야기 네트워크"
- 주민마다 **성격**(수다쟁이·수줍음·장난꾸러기·성실·호기심…), 좋아하는 것·싫어하는 것, 직업, 집, 가족, 돈
- **기억**: 본 일·들은 일·한 일을 기억 (언제·어디서·누구와·기분) → 시간이 지나면 흐려지고, 중요한 건 오래 남음
- **소문**: 친구에게 이야기를 전하고, 그 친구가 또 다른 친구에게… (조금씩 부풀려지기도 ㅋㅋ)
- **질문**: 모르는 일을 서로 물어봐요 — "새로 이사 온 사람 봤어?", "어제 불난 데 어디야?"
- **만남과 관계**: 처음 본 사람 → 아는 사이 → 친구 → 단짝 → 연인 → 결혼 / 다투고 화해
- **이사 오고 가기**: 일자리·집·행복도에 따라 새 주민이 이사 오고(이삿짐 트럭), 떠나기도 해요
- **수만 개의 이야기**: 문장 조각 수천 개 × 주민·장소·물건·사건 조합 + 기억 → 같은 말이 거의 반복되지 않아요
- **솔방울 신문**: 매일 아침 동네 소식 (결혼, 새 가게, 화재, 도둑 잡힘, 새 이웃) — 주민들이 신문 이야기도 해요
- 인터넷 없이 휴대폰 안에서 혼자 돌아가요 (공짜, 빠름). 원하시면 나중에 "주민과 직접 수다 떨기"에 진짜 AI 대화를 붙일 수도 있어요

## 4. 경찰과 사건 (귀엽게!)
- 사건: **좀도둑**(빵·생선 슬쩍), 가게 줄 새치기, 눈덩이로 창문 깨기, 주민끼리 **다툼**(만화처럼 먼지구름 속 별·주먹)
- 경찰관 출동(호루라기·경찰차 사이렌) → **추격전**(귀여운 추격 음악) → 체포(손을 뒤로) → 경찰서 → 반성하고 석방
- 못 잡으면 **현상수배 포스터**가 게시판에 붙고, 주민 제보로 잡아요 → 촌장 미션 "도둑을 찾아라"
- 사건은 모두 **이야기로 기억**돼요 ("그 도둑 결국 잡혔대!")

## 5. 화재와 소방관
- 원인: 난로·굴뚝·요리 → 연기 → 주민이 신고 → **소방차 출동**(사이렌), 소방관이 호스로 물을 뿌려요 → 김이 피어오르며 꺼짐
- 늦으면 **불에 탄 건물**(그을린 기둥·검댕) → 굴착기·덤프트럭 **철거** → 공사장 → **새 건물**(보험 + 대출, 가끔 더 좋게)
- **아무도 다치지 않아요** — 모두 대피하고, 구경하던 주민들이 박수
- 화재 예방: 소방서 레벨, 소화전 설치 → 빨리 끔

## 6. 안전 장치
- 사건·사고는 가끔만 (마을이 행복하면 더 드물게)
- 설정에서 **"사건·사고 끄기"** 가능 (끄면 도둑·싸움·화재 없음)

## 7. 만드는 순서
- **지금 바로**: 물류센터·은행·경찰서·소방(불·불탄 건물·철거 차량)·이삿짐 그림, 직원·소방관·도둑 등 새 옷과 동작(달리기·도망·다툼·체포·물 뿌리기), 불·물줄기·먼지구름 효과와 아이콘·신문 화면, 사이렌·불·은행·물류센터 소리, **이야기 엔진**(주민 대화·기억·소문 프로그램 + 한국어 문장 수천 개 + 샘플 이야기 모음)
  → 각각 검사관이 꼼꼼히 보고 → 고치기
- 게임에 넣기: **이야기 엔진과 은행은 v5**(주민의 일생과 함께), **물류센터·경찰·소방·이사는 v8 "살아 있는 도시"**
