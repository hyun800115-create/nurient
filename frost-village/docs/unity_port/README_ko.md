# 유니티 시험판 안내 — 쉬운 설명

「행복한 눈꽃마을 이야기」를 유니티로 옮겨서, 휴대폰에서 "이대로 가도 되겠다 / 안 되겠다"를 판단할 수 있는
**시험판**을 만드는 계획이에요. 자세한 기술 문서는 같은 폴더의 `00_architecture.md`에 있어요.

만드는 곳: PC의 `D:\Work\Snowbloom\` 폴더 안이에요.

- `D:\Work\Snowbloom\SnowbloomUnity` — 새 유니티 게임 폴더(여기에 옮겨 만들어요)
- `D:\Work\Snowbloom\nurient` — 지금 게임의 복사본(그림·자료를 가져오기만 하고, 고치지 않아요)

---

## 1. 시험판에 들어가는 것

시험판을 **두 번에 나눠서** 드리는 걸 추천해요.

**1차 시험판 (먼저)**

- 새 게임을 시작하면 땅, 길, 처음 건물들이 지금 게임과 **같은 자리, 같은 앞뒤 순서**로 나와요.
- 촌장님이 건물 뒤로 가면 건물이 **반투명**해져요.
- 화면 조이스틱으로 걷고, **땅을 톡 치면 그곳으로 걸어가요**(설정에서 끌 수 있어요). 카메라가 따라오고, 두 손가락으로 같은 범위만큼 확대·축소돼요.
- 주민 4명(할아버지, 아주머니, 여자아이, 장난꾸러기)과 강아지 누리가 광장을 돌아다녀요.
- 첫 장사: 생선 낚기 → 화덕 → 노점 → 계산대 → 동전. 화면 위 동전 숫자가 올라가요. 손님 모습도 여러 가지예요.
- 저장과 불러오기: 앱을 껐다 켜도 그대로예요.
- 어부를 고용하면 「여기까지가 시험판이에요」가 나오고 끝나요.

**2차 시험판 (그다음)**

- 지금 게임의 **예전 마을 코드**(마을 옮기기)를 붙여 넣으면 그 마을 모습이 나와요. 역, 마을회관, 큰 식당, 촌장 사무소, 은행, 물류센터도 그려요.
- 단, 기찻길과 읍내 거리 그림은 눈밭으로 보이고, 읍내 사람들과 건물 안쪽은 아직 없어요. 이 점은 미리 약속해 두고 싶어요.

**버그가 아니라 일부러 다른 점**

- 호루라기·목표 버튼은 모양만 있고, 누르면 「준비 중이에요」가 떠요.
- 첫 판매 뒤에 아이콘이 바뀌지 않고, 촌장님 빛 고리 모양이 조금 달라요.
- 주민이 처음부터 바로 나와요(지금 게임은 몇 초 뒤에 나와요).
- 바다는 '저사양'일 때의 바다 모양이에요.

## 2. 진행 순서

1. **준비** — PC에 프로그램을 설치하고 빈 프로젝트를 만들어 휴대폰에 시험용 앱을 한 번 깔아 봐요.
2. **정답지 만들기** — 같은 시간에 다른 Claude가 지금 게임을 자동으로 돌려서, 무엇이 어디에 어떤 순서로 그려지는지, 장사가 몇 초에 어떻게 흘러가는지를 기록해요. 유니티 쪽은 이 기록과 똑같은지 기계로 비교해요.
3. **만들기** — 땅과 건물 → 조작과 카메라 → 주민 → 반투명 → 첫 장사 → 저장 순서로 만들어요. 단계마다 휴대폰으로 짧게 확인을 부탁드려요.
4. **1차 시험판 전달** — 10분쯤 해 보시고 판단해 주세요.
5. **2차 작업** — 예전 마을 불러오기를 붙여서 다시 전달해요.

## 3. PC에서 해 주실 일

**① 설치 (처음 한 번, 반나절쯤)**

- 유니티 허브와 유니티 **6000.3 (6.3 LTS)** 는 이미 설치하셨어요(2026-11-21). 안드로이드 빌드 지원(OpenJDK, Android SDK & NDK)이 빠졌으면 허브에서 추가해 주세요.
- 허브에 로그인해서 무료(Personal) 사용 허가를 켜 주세요.
- 나머지 도구(Git, .NET 10, Node, GitHub 도구)는 Claude가 설치 명령을 실행해요. 허락을 물으면 '예'를 눌러 주세요.
- 휴대폰 **기종**을 알려 주시고, 지금 게임 화면(동전 숫자와 글씨가 보이는 화면)을 **캡처해서 보내** 주세요. 휴대폰에 실제로 보이는 글씨체를 고르는 데 써요.

**② 프로젝트 열기**

- 유니티 허브 → 「추가」 → `D:\Work\Snowbloom\SnowbloomUnity` 선택. 처음 열 때는 몇 분 걸려요.
- Claude가 자동 검사나 앱 만들기를 할 때 "유니티 창을 닫아 주세요"라고 부탁할 수 있어요.

**③ 재생 버튼 눌러 보기**

- 화면 위 가운데의 ▶ 버튼을 누르면 게임이 시작돼요. 한 번 더 누르면 멈춰요.
- PC에서는 마우스로 끌기 = 조이스틱, 마우스 휠 = 확대·축소, W·A·S·D 키 = 이동이에요.
- 두 손가락 확대·축소는 **휴대폰에서만** 확인할 수 있어요.

**④ 휴대폰에서 확인**

- Claude가 보낸 링크(또는 파일)를 휴대폰에서 열고 내려받아 설치해요. 처음에 「출처를 알 수 없는 앱 설치 허용」을 켜 주세요.
- 지금 게임과 나란히 비교해요. 모습은 크롬에서 지금 게임을 '저사양'으로 켜고 보고(조금 흐릿하게 보이는 건 정상이에요), 손맛은 평소 설정으로 비교해요. Claude가 비교용 링크를 따로 드려요.
- 확인할 것: 처음 화면이 같은지, 건물 앞뒤와 반투명, 조이스틱과 카메라, 땅 톡 치기, 주민, 첫 장사 시간과 동전, 글씨, 껐다 켜도 그대로인지, 끊김 없이 부드러운지.

## 4. 얼마나 걸리나요

| 단계 | Claude 두 개가 동시에 | Claude 하나 |
|---|---|---|
| 1차 시험판 | 약 4.5~5주 | 약 6주 |
| 2차 시험판 | 약 1.5~2주 더 | 약 2주 더 |

- 사람이 쓰는 시간: 설치 반나절, 휴대폰 확인 15~30분씩 6번쯤.
- 처음 계획(2~3주)보다 길어요. 똑같이 보이게 하려면 그림 순서, 글씨, 손님 모습, 예전 마을 건물까지 챙겨야 하고, 유니티는 검사와 앱 만들기에 시간이 꽤 걸리기 때문이에요.
- 더 빨리 원하시면 **한 번에 내는 안**도 있어요. 빛 고리·말풍선 빼기, 점원이 걸어오지 않고 제자리에 있기, 그래픽 자동 조절 빼기 등으로 1주쯤 줄어요.

## 5. 정해 주실 것

1. 시험판을 **두 번에 나눌지** (추천: 나누기)
2. **땅 톡 치면 걷기**를 처음부터 켜 둘지 (추천: 켜기)
3. **글씨체** — 보내 주신 휴대폰 화면을 보고 추천드릴게요
4. 예전 마을에서 **기찻길·거리 그림 대신 눈밭**으로 보여도 괜찮은지
5. 새 비공개 저장소(GitHub)를 어느 계정에 만들지
6. (참고만) 색이 겹칠 때 섞이는 방식 두 가지를 사진 두 장으로 보여드릴게요. 시험판은 지금 게임과 같은 방식으로 만들고, 나중에 본 작업에서 어느 쪽으로 갈지 함께 정해요
