# 마을회관 게시판 — 어디로 가져가나요? (v4.2 고침)

> 디자이너님 질문: "마을회관 오늘의 부탁 … 통조림 내가 가져다 줘도 안 들어가지네"

## 1. 왜 안 들어갔나요

- 게시판의 **오늘의 부탁**은 마을이 지금 필요한 것을 **알려 주는 곳**이에요. 마을회관이 물건을 받는 곳은 아니에요.
- "정기 납품: 통조림 23/30" 은 **서리역 앞 '짐 싣는 곳'** 에 통조림을 놓아야 채워져요 (솔방울 주문판과 같은 주문이에요).
- 그런데 예전 게시판에는 **어디로 가져가는지가 안 쓰여 있었어요.** 그래서 통조림을 들고 마을회관으로 가셨던 거예요.

## 2. 이렇게 바뀌었어요

- 부탁마다 **가져갈 곳**이 한 줄 더 쓰여요. 예: `정기 납품: 통조림 23/30` 아래에 `→ 서리역 짐 싣는 곳`.
- 부탁 오른쪽에 **[길 안내]** 표시가 있어요. 부탁을 **누르면** 게시판이 닫히고, 그곳까지 **길 안내**(바닥의 점, 화살표, 아래쪽 칩 `→ 서리역 짐 싣는 곳 · 87m`)가 시작돼요.
  - 손에 아무것도 없어도 안내해요.
  - 도착하면 "서리역 짐 싣는 곳에 왔어요" 하고 안내가 끝나요. 들고 간 통조림은 거기 발판에 서 있으면 주문으로 들어가요.
  - 주문이 다 채워지면 (다른 짐꾼이 채워도) 안내는 저절로 끝나요. 아래 칩을 **꾹 누르면** 안내를 끌 수 있어요.
  - 4분이 지나도 저절로 끝나요 (`balance.js` → `v42.nav.pinMaxS`, 도착 거리 `pinArrivePx`).

| 게시판 부탁 | 가져갈 곳 (길 안내가 가는 곳) |
|---|---|
| 솔방울 주문 / 정기 납품 (`{가게}: {물건} 23/30`) | **서리역 짐 싣는 곳** |
| 큰 식당에 ○○이(가) 떨어져 가요 | **큰 식당 식재료 칸** |
| 집을 기다리는 주민 ○명 | **빈 부지 (집 짓기)** — 집을 지을 수 있는 가장 가까운 빈 부지 |
| 광부들이 배가 고파요 | **광부 식량 상자** |

### 마을회관이 직접 받게 하지 않은 이유

- 같은 물건을 받는 곳이 두 군데가 되면 헷갈리고, 마을회관에 쌓인 물건을 역까지 옮길 짐꾼이 또 필요해요.
- 짐꾼이 없을 때 물건이 마을회관에 그냥 쌓여 있게 돼요 (이번처럼 "안 들어가네" 가 다른 모양으로 또 생겨요).
- 그래서 **받는 곳은 하나 그대로**, 대신 **어디인지 알려 주고 데려다 주는** 쪽으로 고쳤어요.

## 3. 마을회관은 레벨이 오르나요?

- **마을회관 자체는 레벨이 없어요.** 한 번 지으면 그대로예요 (세금 상자, 게시판, 집 자리 +6, 행복 +8).
- 대신 **마을 등급**이 올라요: **서리마을 → 서리읍**.
- 등급은 마을회관 앞 **승격식 발판**에서 올려요. 조건을 다 채우면 발판에 코인을 내고 승격식을 해요.

| 승격식 조건 (마을 → 읍) | 값 |
|---|---|
| 주민 | 45명 |
| 연 가게 (역 앞) | 5곳 |
| 행복 | 80 |
| 승격식 비용 | 11,000 코인 |

- 왼쪽 위 **등급 칩**(마을 + 막대 3개)을 누르면 지금 몇이 찼는지 보여요.
- 값은 `balance.js` → `v4.rank` 에서 바꿀 수 있어요.
