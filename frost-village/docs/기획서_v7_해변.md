# 서리마을 v7 기획 — 살아 있는 바다와 "햇살 해변" 해수욕장 (대표님 아이디어)

> "바닷물도 진짜처럼 보이게 잘 만들어줘. 출렁 파도치고, 해변가 해수욕장도 만들어주고,
> 해변가 주변 상가들과 호텔, 그와 관련된 NPC들, 오브젝트들도."

## 1. 진짜 같은 바다 (모든 바다에 적용 — 서리마을 앞바다, 갈매기 항구, 해변)
지금 바다는 그림 한 장이 천천히 미끄러지는 정도라 밋밋해요. 이렇게 바꿔요:
| 무엇 | 어떻게 보이나 |
|---|---|
| **출렁이는 너울** | 큰 물결이 천천히 해안 쪽으로 밀려오며 밝은 줄·어두운 줄이 움직여요 |
| **잔물결과 햇빛 반짝임** | 작은 물결이 두 방향으로 겹쳐 흐르고, 햇빛이 반짝반짝 튀어요 |
| **깊이에 따른 색** | 먼 바다는 짙은 남색 → 해안 가까이는 청록색 → 얕은 곳은 투명해서 바닥 모래가 비쳐요 |
| **밀려오는 파도** | 모래 해변에서는 하얀 거품 파도가 밀려왔다가 쓸려 나가고, 젖은 모래가 어둡게 남아요 |
| **바위·방파제에 부딪히는 파도** | 철썩! 물보라가 튀어요 |
| **부두·배 주변** | 배가 지나가면 물살이 갈라지고(항적), 배·부표·수영하는 사람이 물결에 맞춰 둥실둥실 |
| **물 밑 빛무늬** | 얕은 물 바닥에 햇빛 물결 무늬(코스틱)가 일렁여요 |
- 휴대폰이 힘들어하면 설정에서 **물결 품질(높음/낮음)** 선택
- 서리마을 앞바다는 겨울 바다 색(짙은 남색·차가운 청록), 해변은 따뜻한 에메랄드색

## 2. "햇살 해변" — 어디에?
- 서리마을은 눈 나라라서, 해수욕장은 **갈매기 항구 남쪽, 따뜻한 바닷물(난류)이 흐르는 해안**에 있어요.
  눈이 녹은 **하얀 모래 해변**, 멀리 눈 덮인 산이 보이는 특별한 휴양지 → 눈 마을과 대비되는 "꿈의 장소"
- 항구도시(v6)와 함께 열려요. 여객선을 타고 온 **관광객**이 해변으로 가서 놀고, 호텔에 묵고, 가게에서 돈을 써요.

## 3. 해수욕장 (놀거리와 소품)
- 모래사장, 젖은 모래, 조개·불가사리·미역·유목, 걸어다니는 **꽃게**
- 알록달록 **파라솔**, 선베드, 비치 타월, **튜브**, 비치볼, **모래성**(크기 3가지), 양동이·삽
- **인명구조 감시탑**(구조요원이 망원경으로 바다를 봐요), 구조 튜브·구조 보드
- 샤워장, 탈의실, 나무 산책로(보드워크), **비치발리볼** 네트, 서핑보드 거치대
- 바다 위: **수영 구역 부표 줄**, **오리배(백조 페달보트)**, 카약, 바나나보트, 물 위 놀이 뗏목
- 야자수·해송, 해변 그네, 피크닉 테이블, **아이스크림 수레**, 옥수수·핫도그 노점, 대여소(튜브·파라솔), 연날리기

## 4. 해변 상가와 호텔
| 건물 | 하는 일 |
|---|---|
| **리조트 호텔** (큰 건물, 발코니, 야외 수영장) | 관광객이 묵어요 → 오래 머물수록 돈을 많이 써요. 벨보이·안내원·도어맨 |
| **작은 펜션(민박)** | 가족 관광객 |
| **해변 카페 / 비치 바** | 음료·간식 (서리마을 빵·생선 납품) |
| **조개구이·해산물 바비큐집** | 서리마을 생선·훈제고기 납품 |
| **아이스크림 가게** | 아이들이 줄 서요 |
| **기념품 가게, 수영복·튜브 가게, 서핑 가게(서핑 교실)** | 관광객 쇼핑 |
| **편의점** | 통조림·빵 납품 |
| **인명구조대 건물, 관광 안내소, 화장실·샤워장** | 해변 운영 |
| **작은 수족관** | 우리가 잡은 물고기 구경 (나중에 "희귀 물고기 기증" 미션) |

## 5. 해변 사람들 (부품 조합 주민 + 새 옷·새 동작)
- **새 옷**: 수영복(원피스), 수영 반바지, 래시가드, 수영모, 밀짚모자·챙 넓은 모자, 선글라스, 슬리퍼, 어깨에 수건, 튜브, 스노클 마스크, 아이 팔튜브
- **직업복**: 인명구조요원(빨강·노랑, 호루라기), 호텔 벨보이·안내원·도어맨·청소원, 아이스크림 장수, 비치바 직원(알로하 셔츠), 서퍼(서핑 슈트), 관광객(카메라·알로하 셔츠)
- **새 동작**: 수영하기(물 위로 머리·어깨만), 튜브 타고 둥실, 선베드에 누워 일광욕, 모래성 쌓기, 비치볼 던지고 받기, 물장구, 서핑
- 주민끼리 이야기: "물이 정말 맑다!", "모래성 대회 나갈 거야", "구조요원 아저씨 멋있다"

## 6. 해변의 소리
- 모래에 부서지는 잔잔한 파도, 멀리 아이들 웃음과 갈매기, 바위에 부딪히는 파도 철썩, 물장구 첨벙
- 구조요원 호루라기, 아이스크림 수레 종, 비치볼 통통, 호텔 안내 종, 모래 발소리
- **해변 음악**: 우쿨렐레·스틸드럼 느낌의 신나는 여름 음악 (마을 음악과 같은 멜로디 가족)
- 서리마을 앞바다용 **진짜 파도 소리**도 새로 (물결이 바뀌니 소리도 함께)

## 7. 게임에서 하는 일 (v6 항구도시와 함께)
- 여객선 관광객 → 해변·호텔·가게 → 우리 마을 물건이 해변 가게로 팔려 나가요 (생선·빵·훈제고기·통조림)
- 호텔 등급 올리기, 해변 시설 늘리기 → 관광객 증가 → 명성
- 촌장 미션: "모래성 대회 열기", "잃어버린 튜브 찾기", "아이스크림 수레에 빵 납품", "여름 불꽃놀이 축제"
- 덤 아이디어: 서리마을 앞바다에서 겨울 **"북극곰 수영 대회"** (새 수영 동작 재활용)

## 8. 만드는 순서
- **지금 바로**: 바다 물결 기술(물결 그림 + 물 그리는 프로그램 + 시험 화면), 모래·해변 소품, 해변 건물·호텔, 해변 사람(옷·동작), 해변 소리 → 각각 **검사관이 꼼꼼히 보고 → 고치기**
- **진짜 같은 바다**는 다음 게임 버전에 바로 넣어요 (서리마을 앞바다부터)
- **해수욕장·호텔·상가**는 v6 항구도시와 함께 게임에 들어가요
