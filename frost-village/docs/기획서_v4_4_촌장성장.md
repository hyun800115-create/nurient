열 가지 모두 넣어요. 한 번에 다 넣으면 시험하기 힘드니까 **여러 번에 나눠서** 넣어요.

- **관리자 모드는 금방(v4.3) 바로 다음, v4.3.1로 드려요.**
  - 대표님이 지금 휴대폰으로 시험하고 계시잖아요.
  - 관리자 모드가 있으면 금방까지 가는 50분을 몇 초로 줄일 수 있어요.

## 지난 계획에서 바뀐 것 (검토를 받고 고쳤어요)

꼼꼼한 검토에서 38가지를 지적받았고, 모두 고쳤어요. 대표님이 아셔야 할 것만 적어요.

1. **관리자 모드에서 '처음부터'를 눌러도 원래 마을은 안전해요.** 지난 계획에는 그 버튼이 원래 마을을 지울 수 있는 틈이 있었어요. 이제 관리자 모드의 모든 저장은 따로 된 칸에만 써요.
2. **가방·신발은 코인으로만** 배워요 (위 표). 처음 마을의 속도가 지금과 똑같아요.
3. **예전 마을의 지나간 퀘스트가 제대로 정리돼요.** 읍이 된 마을이면 Lv 17로 시작해요.
4. **쉬는 동안 번 돈은 하루 합계**로 셈해요.
5. **금방 퀘스트가 막히지 않아요.** 이미 해 둔 일(편지, 개업, 첫 배달, 업그레이드)도 바로 인정해요.
6. **보상 코인이 정확해져요.** 게임을 다시 켠 직후에도 '그때 수입'에 맞는 보상을 줘요.
7. **v5용 게시판·부탁 말풍선은 v4 동안 꺼 둬요.** 아직 준비가 덜 된 부분이 읍에서 켜지지 않게요.
8. 버전을 조금 더 잘게 나눴어요: v4.3 → v4.3.1 → v4.4 → v4.4.1 → v4.5 → v4.6. 버전마다 검토와 고치기를 한 번씩 더 해요 (13장).

## 1. 촌장님 이름과 호칭 (v4.3.1)

### 1.1 어떻게 보여요

- **새로 시작할 때**: 타이틀을 누르면 이름 짓는 창이 떠요.

  ```
  ┌──────────────────────────────┐
  │        (촌장님 얼굴)           │
  │   촌장님의 이름을 지어 주세요   │
  │  ┌──────────────────┐ 3/8     │
  │  │ 눈송이▌           │         │
  │  └──────────────────┘         │
  │  [추천 이름] 눈송이 · 솔방울…   │
  │    [나중에]    [이걸로 할게요]  │
  └──────────────────────────────┘
  ```

- **글자**: 1~8글자예요 (한글 한 글자 = 1). 한글, 영어, 숫자, 띄어쓰기, `·`를 쓸 수 있어요.
- **추천 이름**: 누를 때마다 눈송이 · 솔방울 · 고드름 · 함박 · 포근 · 서리별 · 몽실 · 눈꽃이 돌아가며 나와요.
- **나중에**를 누르면 그냥 "촌장님"이에요. 나중에 언제든 지을 수 있어요.
- **이름 바꾸기**: 설정의 새 칸 **촌장** › `촌장 이름 ✎` 에서 언제든 공짜로 바꿔요. v4.4부터는 스킬 창 위쪽에서도 돼요.
- **예전에 하던 마을**: 처음 켜고 마을이 보인 뒤 3초쯤 지나서 한 번 물어봐요.
- **한글 입력**: 휴대폰 한글 자판(천지인, 쿼티)에서 글자가 잘리거나 두 번 써지지 않게 특별히 챙겼어요.
  - 글자를 다 쓰자마자 자판을 닫지 않고 `이걸로 할게요`를 눌러도 마지막 글자가 잘리지 않아요 ("눈송이"가 "눈송"이 되지 않아요).
  - 이름 칸을 누르기 전에는 자판이 저절로 올라오지 않아요.
  - 자판이 올라와도 이름 칸과 버튼이 가려지지 않아요. 아이폰에서도 화면이 갑자기 확대되지 않아요.

### 1.2 이름이 나오는 곳

- 주민 인사: `눈송이 촌장님!`
- 편지: `눈송이 촌장님께`
- 승격식: `눈송이 읍장님, 축하해요!`
- 사무실 화면 제목
- 금방 정 할머니 편지
- 주민과 수다 떨 때
- 타이틀 아래 한 줄: `눈송이 촌장님, 어서 오세요`
- v4.4부터 스킬 창 위쪽

### 1.3 호칭은 마을과 함께 커져요

| 마을 | 호칭 | 화면에 |
|---|---|---|
| 서리마을 | 촌장 | 눈송이 촌장 |
| 서리읍 (승격식 뒤) | 읍장 | 눈송이 읍장 |
| 서리시 (v5) | 시장 | 눈송이 시장 |
| 큰 도시 (v8) | 시장 (금빛 배지) | 눈송이 시장 |

### 1.4 설정의 새 칸 '촌장'

설정 창 위쪽 탭이 `[소리·화면] [놀이] [촌장]` 세 개가 돼요. '놀이' 칸은 이미 꽉 차서 새 칸을 만들었어요.

| 줄 | 하는 일 | 언제부터 |
|---|---|---|
| 촌장 이름 ✎ | 이름 바꾸기 | v4.3.1 |
| 저장 코드 내보내기 / 가져오기 | 3장 | v4.3.1 |
| 보관된 마을 불러오기 | 안전하게 보관해 둔 예전 마을을 다시 열어요 (3.1) | v4.3.1 |
| 경험치 숫자 | 촌장님 머리 위 `+3` 숫자 켜기/끄기 | v4.4 |
| 미션 알림 | 미션 알림 켜기/끄기 | v4.5 |
| 부족 알림 | 자원 부족 알림 켜기/끄기 | v4.6 |

로그인이 들어오면 네 번째 탭 `계정`이 생겨요.

## 2. 관리자 모드 사용법 (v4.3.1)

### 2.1 여는 법

1. 오른쪽 위 **톱니바퀴(설정)** 를 눌러요.
2. 설정 창 **위쪽, 탭 바로 위**에 있는 작은 글씨 **`v4.3.1 · 날짜`** 를 톡톡 눌러요. 3번째부터 `관리자 모드까지 4번` 처럼 남은 횟수가 떠요.
3. **7번째**에 창이 떠요:
   `관리자 모드는 시험해 보는 곳이에요. 지금 마을은 따로 보관하고, 연습용 마을에서 마음껏 놀 수 있어요.`
4. **켜기**를 누르면 화면 위쪽(선물 상자 자리)에 빨간·금색 **`관리자`** 띠가 생겨요. 이 띠를 누르면 관리자 버튼들이 나와요.

### 2.3 원래 마을로 돌아가기

관리자 버튼 맨 아래에 네 가지가 있어요.

| 버튼 | 하는 일 |
|---|---|
| **원래 마을로 돌아가기** (보통 이것) | 관리자를 켜기 전 마을이 **한 글자도 안 바뀐 채로** 돌아와요. 관리자 마을은 다음에 또 쓸 수 있게 남아요 |
| 관리자 마을 지우기 | 연습용 마을을 지워요 |
| 이 마을로 계속하기 | 연습용 마을을 진짜 마을로 삼아요. 두 번 물어봐요. 원래 마을은 '보관된 마을'에 남아요 |
| 원래 마을 되살리기 | 혹시 원래 마을이 사라졌을 때, 관리자를 켤 때 보관해 둔 사본을 다시 꺼내요 (보통은 쓸 일이 없어요) |

**안심하세요**:
- 관리자 모드 중에는 원래 마을 저장을 **절대 건드리지 않아요**. 관리자 모드에서 **설정 › 처음부터**를 눌러도 지워지는 건 연습용 마을뿐이에요.
- 관리자 마을이 고장 나서 다시 켜져도, 고장 난 것은 연습용 마을만 따로 치워요.
- 이 모든 경우를 시험으로 확인해요: 처음부터 누르기, 일부러 고장 내기, 타이틀로 돌아가기 → 그다음 원래 마을이 한 글자도 안 바뀌었는지 비교해요.
- 관리자 마을은 클라우드에 올라가지 않아요.
- 관리자 마을에서는 출석·선물·쉬는 동안 번 돈을 받지 않아요.

## 3. 저장 코드 (v4.3.1, 로그인 없이 옮기기)

- **어디에**: 설정 › **촌장** › **저장 코드** › `내보내기` / `가져오기`.
- **내보내기**: 긴 글자(예: `SV7.3fa9….`)가 나와요.
  - `복사`를 누르면 복사돼요. 메모장이나 카카오톡 나에게 보내기에 붙여 두세요.
  - 아티팩트에서는 `파일로 저장`도 돼요. 앱(APK)에서는 v4.6부터 파일로도 저장돼요 (그 전에는 복사만).
  - 오래된 휴대폰에서도 돼요 (글자가 조금 길어질 뿐이에요).
- **가져오기**: 다른 기기에서 그 글자를 붙여 넣어요.
  - `눈송이 촌장 · 코인 18,000 · 12시간` 같은 미리보기를 보고 `불러오기`.
  - 지금 마을은 '가져오기 전 마을' 칸에 따로 보관돼요 (다른 보관본을 덮어쓰지 않아요).
  - 관리자 마을의 코드면 미리보기에 `관리자 마을`이라고 나오고, 진짜 마을로 삼기 전에 두 번 물어봐요.
- **이럴 때 좋아요**: 휴대폰 앱(APK)에서 하던 마을을 컴퓨터의 아티팩트로 옮길 때, 그리고 그 반대로.
- QR 코드는 안 만들었어요. 마을 저장이 커서 휴대폰 카메라로 읽기 힘든 크기예요.
- 주민과의 수다 기록은 같이 안 옮겨져요. 마을만 옮겨져요.

### 3.1 마을 지키기 (v4.3 · v4.3.1)

- **예전 창이 새 마을을 덮어쓰지 않아요** (v4.3): 새 버전에서 저장한 마을을 예전 버전 창이 만나면, 저장하지 않고 `새 버전에서 저장된 마을이에요 · 새로 고침해 주세요` 라고 알려 줘요.
- **창 두 개** (v4.3.1): 같은 브라우저에서 게임을 두 창으로 열면, 나중 창만 저장해요. 먼저 창에는 `다른 창에서 마을을 열었어요 · 이 창은 쉬어요` 가 떠요.
- **보관된 마을 불러오기** (v4.3.1): 게임이 안전을 위해 따로 보관해 둔 마을(예: 너무 새 버전이라 못 연 마을, 가져오기 전 마을)이 있으면 설정 › 촌장에서 골라 다시 열 수 있어요.

## 4. 촌장 레벨과 경험치 (v4.4)

### 4.1 화면에서

- **레벨 동그라미**: 왼쪽 위 코인 칸 바로 왼쪽에 생겨요. 숫자(레벨)와 경험치 고리가 보여요.
  - 스킬 포인트가 남아 있으면 **빨간 점**이 떠요.
  - 가방·신발을 살 코인이 모이면 **작은 코인 점**이 떠요.
  - 누르면 스킬 창, 꾹 누르면 이름·호칭·경험치 숫자가 보여요.
- **경험치 숫자**: 촌장님 머리 위로 작은 `+3` 숫자가 퐁퐁 떠요. 설정 › 촌장에서 끌 수 있어요.
- **레벨이 오르면**: 반짝이는 빛과 소리, `촌장 레벨 12!` · `스킬 포인트 +1`, 그리고 `스킬 보기` 버튼이 나와요.

### 4.2 무엇을 하면 경험치가 생겨요 (촌장님이 직접 한 것만)

| 하는 일 | 경험치 |
|---|---|
| 물고기 잡기 · 나무 베기 · 밀 거두기 · 광석 캐기 (하나에) | 1 (사냥은 3) |
| 가공소에서 직접 굽기·만들기 (하나에) | 1 |
| 계산대에서 손님 계산 | 2 |
| 물건 나르기 (3개마다, 하루 1,500까지) | 1 |
| 일꾼·직원 고용 | 20~30 |
| 땅 열기 / 망루 불 켜기 | 40 / 80 |
| 건물 다 짓기 | 15~120 (클수록 많이) |
| 가게 개업 / 승격식 | 50 / 500 (+ 스킬 포인트 2) |
| 주민과 수다 / 인사 / 누리와 놀기 | 10 / 5 / 5 (하루 10번까지) |
| 편지 답장 / 아침 신문 | 15 / 10 |
| 퀘스트 · 미션 · 출석 | 각자 정해진 만큼 |

- **일꾼이 한 일**은 경험치가 없어요. 촌장님이 직접 해야 해요.
- **창고에 넣기**와 **집어 온 곳에 도로 넣기**는 경험치가 없어요 (같은 물건을 왔다 갔다 해서 레벨을 올리는 꼼수를 막아요).
- **관망 모드** 중에는 4분의 1만 생겨요. 20분 동안 화면을 안 만지면 `촌장님이 꾸벅꾸벅 졸아요` (경험치 0, 코인은 계속 벌어요).

### 4.3 얼마나 빨리 올라요 (하루 30분 노는 분 기준, 이야기 퀘스트가 들어온 v4.4.1부터)

| 언제 | 레벨 |
|---|---|
| 처음 3분 | Lv 2 |
| 첫날 (30분) | Lv 11 |
| 읍이 될 때 | Lv 15~17 |
| 일주일 | Lv 24 |
| 한 달 | Lv 36 |
| 약 40일 | Lv 40 (스킬을 다 배워요) |
| 넉 달쯤 | Lv 60 (최고) |

- 퀘스트가 경험치의 절반쯤을 줘요. 그래서 **v4.4만 있을 때는 레벨이 조금 느리게** 올라요 (첫날 Lv 6~9). v4.4.1이 오면 그동안 한 퀘스트를 한꺼번에 쳐 줘서 표대로 돼요.
- **레벨이 올라도 코인은 안 줘요.** 대신 스킬 포인트를 줘요. 코인이 넘치면 게임이 시시해져요.
- 레벨 10, 20, 30 … 60마다 꾸미기 쿠폰을 한 장씩 드려요 (v4.4.1부터, 이미 지난 레벨 몫도 드려요).

## 5. 스킬 창 (v4.4)

### 5.1 어떻게 생겼어요

```
┌──────────────────────────────────────────┐
│ (Lv 12)  눈송이 읍장  ✎      스킬 포인트 3 │
│ ▓▓▓▓▓▓▓▓▓▓░░░░  다음 레벨까지 230        │
│ [일솜씨] [건축] [사람] [지혜]              │
│ ┌──────────────────────────────────────┐ │
│ │ 🎒 큰 가방      ●●●○○○  장비          │ │
│ │ 한 번에 18개 → 22개                    │ │
│ │                    [배우기 · 300코인]   │ │
│ ├──────────────────────────────────────┤ │
│ │ ✋ 손재주       ●○○   재능             │ │
│ │ 직접 굽기 +10 % → +20 %                │ │
│ │                    [배우기 · 포인트 1]  │ │
│ └──────────────────────────────────────┘ │
│        [재능 다시 배우기 (처음 1번 무료)]   │
└──────────────────────────────────────────┘
```

- **네 갈래**: 일솜씨 · 건축 · 사람 · 지혜.
- **두 가지 스킬**:
  - **장비**(큰 가방, 가벼운 발걸음): **코인으로** 배워요. 예전 작업대 값 그대로예요. 레벨 제한도 없어요 (새로 생긴 가방 30개 단계만 Lv 20).
  - **재능**(나머지 12가지): **스킬 포인트로** 배워요. 단계마다 `Lv 6에 배울 수 있어요` 같은 레벨 제한이 있어요.
- **스킬 포인트**는 레벨이 오를 때(5의 배수 레벨은 2개), 이야기 한 장이 끝날 때, 승격식 때 생겨요.
- **가방·신발 카드는 처음부터 보여요** (나무꾼을 고용하기 전에는 `나무꾼을 고용하면 배울 수 있어요` 로 잠겨 있어요). 가방이 어디로 갔는지 처음부터 알 수 있게요.
- **재능 카드는 그 마을에 필요해지면 나타나요.** 예: 광부를 고용하면 건축 스킬이 나타나요.
- **배울 때**: `큰 가방 4단계를 배울까요? (300코인)` 하고 한 번 물어봐요. 배우면 촌장님이 반짝이고 `큰 가방 4단계! 한 번에 22개` 가 떠요.
- **재능 다시 배우기**: 재능 스킬은 포인트를 돌려받고 다시 고를 수 있어요 (가방·신발은 코인으로 산 것이라 그대로예요).
  - 처음 한 번은 무료예요.
  - 그다음은 5분 수입쯤의 코인이 들고, 하루 한 번만 돼요.
  - 새 스킬이 생기는 버전(v4.5, v4.6)마다 한 번 더 무료예요.

### 5.3 가방·신발은 이렇게 옮겨요

- **지도에서**: 광장의 가방·신발 발판 두 개가 없어져요. 의자는 꾸미기로 남아요.
- **처음 하는 분**:
  - 예전에 작업대를 가리키던 **화살표가 이제 레벨 동그라미를 가리켜요.** 가방을 살 코인이 모일 때마다요 (예전 작업대와 같은 때).

## 7. 우편함과 보관함 (v4.4.1)

- **우편함**(받을 것): 받을 것이 있으면 오른쪽 위에 **편지 아이콘 + 숫자**가 떠요. 없으면 숨어요.
  - 퀘스트 보상, 출석, 선물 상자의 코인·경험치·스킬 포인트·간식·반짝 후광이 여기 모여요.
  - 보상 금액은 **받을 때가 아니라 생길 때** 정해져요. 언제 눌러도 같아요.
  - `모두 받기` 버튼도 있어요.
  - **20칸**까지 들어가요. 넘치면 가장 오래된 것부터 저절로 받아요. 잃는 건 없어요.
- **보관함**(물건): 우편함 창의 두 번째 탭이에요. **꾸미기 쿠폰과 선물 꾸미기**가 여기 개수로 모여요.
  - **꾸미기 쿠폰** (눈사람 동상, 쉼터 의자, 가로등, 놀이터, 분수 공원):
    - 짓기 메뉴에서 그 꾸미기에 `쿠폰 1장` 이 붙어요.
    - **코인이 공짜**예요 (재료는 필요해요).
  - **선물 꾸미기** (이글루, 랜턴 줄, 그네, 눈 요새, 꽃 수레, 결혼식 아치):
    - 집터가 필요 없어요. 광장·공원·마을회관 앞의 **선물 자리** 중 하나를 고르면 바로 생겨요.
    - 선물 자리는 마을 12곳, 읍이 되면 16곳, 도시가 되면 20곳이에요.
    - 놓은 선물을 꾹 누르면 `치우기` 로 보관함에 다시 넣을 수 있어요. 자리를 바꾸고 싶을 때 좋아요.
  - 같은 것은 9개까지 모여요. 10개째부터는 하나에 경험치 50으로 바꿔 드려요.
  - **쿠폰과 선물은 절대 사라지지 않아요.**

  - 화면을 만지며 노는 시간만 세요. 관망 모드는 반만 쳐요 (그것도 1분 안에 화면을 만졌을 때만. 충전기에 꽂아 두고 관망만 켜 두면 안 쌓여요).
- **어디에**: 오른쪽 위 우편함 옆. 동그란 시계 고리가 차오르고, 다 차면 상자가 흔들흔들해요. 누르면 열려요.
- **선물**: 코인 (15초 · 30초 · 45초 수입), 15분 상자에는 누리 간식이나 꽃 한 송이도 들어 있어요.
- 안 연 상자는 다음 날 우편함에 들어가요.

### 9.3 쉬는 동안 번 돈

- **언제**: **마을이 완성된 뒤**부터예요. 그 전에는 `촌장님이 안 계시니 마을이 조용히 기다렸어요`.
- **창**: 다시 켜면 `촌장님이 없는 동안 · 마을 사람들이 2시간 10분 동안 일했어요 · +2,600 · 받기`.
  - 사무실이 있으면 소복이가 `장부 정리했어요!` 하고 건네줘요.
- **얼마나**: 30분 평균 수입의 **4 %**를, **하루에 모두 합쳐 3시간 몫**까지 (10분 넘게 쉬었을 때만).
  - 하루에 세 번 켜도, 한 번 켜도 하루 합계는 같아요. 하루 몫을 다 받으면 `오늘 몫은 다 받았어요 · 내일 새벽 5시에 다시 쌓여요` 라고만 알려 줘요.
  - 3시간 몫은 7분쯤 논 만큼이에요.
  - '든든한 금고' 스킬을 배우면 하루 4시간, 5시간 · 5 %까지 늘어요.
- **왜 조금만**: 많이 주면 "켜 두고 안 노는 게임"이 돼요.
- 코인만 쌓이고, 물건이나 이야기는 그대로 기다려요.

## 10. 주민 행복도 · 지역 자원 (v4.6)

### 10.1 주민 행복도

- **누구**: 우리 마을 주민 한 사람 한 사람이에요 (솔방울 마을 이웃은 지금처럼 '손님 만족'으로 세요).
- **바라는 것 일곱 가지** (100점 만점):

  | 바라는 것 | 이럴 때 행복해요 |
  |---|---|
  | 먹거리 | 좋아하는 음식(생선 / 빵 / 고기)이 판매대에 늘 있을 때 |
  | 집 | 집이 있을 때 (돌집이면 더) |
  | 일·배움 | 어른은 일자리, 아이는 놀이터, 어르신은 가까운 의자·분수 |
  | 가게 | 열린 가게가 많을 때, 금방이 집 앞까지 배달해 줄 때 |
  | 꾸미기 | 집 근처 꾸미기가 많을 때 |
  | 즐길 거리 | 공연·눈싸움·잔치에 끼었을 때 |
  | 촌장님 | 이틀 안에 촌장님이 인사하거나 수다 떨어 줬을 때 |

- **화면에서**:
  - 주민을 누르면 얼굴 표정(5가지)과 점수, 가장 아쉬운 두 가지가 아이콘으로 보여요.
  - 말풍선이 `빵이 먹고 싶어요…` 처럼 무엇이 필요한지 말해 줘요.
- **좋은 점만 있어요**: 행복하면 이주민이 더 자주 오고, 세금이 조금 더 걷히고, 일꾼이 5 % 빨리 일하고, 기차 손님이 늘어요.
  - **행복이 낮아도 벌은 없어요.** 시무룩한 표정과 말풍선으로 알려 줄 뿐이에요.
- **승격식 막대는 지금 그대로**('손님 만족')예요. 주민 행복은 그 옆에 함께 보여 줘요. 그래서 읍이 되는 빠르기는 지금과 같아요. (지난 계획처럼 둘 중 높은 쪽을 쓰면 읍이 너무 쉬워져서 바꿨어요.)

### 10.2 지역 자원

- **여는 법** (새 버튼 없이 지금 있는 것에):
  - 왼쪽 위 **주민 수 칩**이나 **'마을' 칩**을 누르면 **마을 창**이 열려요: 등급 · 행복 · **자원** · 통계.
  - 오른쪽 아래 **지도 버튼**으로 전체 보기를 하면 위쪽에 `[마을 보기 | 자원 지도]` 가 생겨요.
    - 자원 지도를 켜면 구역마다 **핀**이 꽂혀요 (빨강 = 부족).
    - 핀을 누르면 그 구역 자원이 보여요.
- **맨 위: 지금 부족한 것 3가지**

  ```
  지금 부족한 것 TOP 3
  🔴 빵이 부족해요 ← 빵 짐꾼이 없어요        [해결하러 가기]
  🟠 제련소 출구가 꽉 찼어요 ← 주괴 짐꾼 필요  [해결하러 가기]
  🔴 집이 부족해요: 이사 기다리는 주민 3명     [해결하러 가기]
  ```

  - `해결하러 가기` 를 누르면 **길 안내**가 고칠 곳(발판·집터)까지 데려가요. '관찰력' 2단계가 있으면 언제나, 없으면 하루 한 번.
- **구역마다**: 나무·바위·밀·물고기·동물이 얼마나 있는지 → 더미 → 가공소 → 판매대, 1분에 얼마 만들고 얼마 쓰는지.
  - 창고, 일꾼(빠진 사람), 주민·빈 방, 기다리는 손님·주문도 보여요.
- **색깔**: 🔴 부족 · 🟡 곧 부족 (관찰력) · 🟠 길 막힘 · 🔵 남음 · 🟢 적당.
- **'관찰력' 스킬**이 있으면 더 자세해져요: 왜 부족한지 → 언제 바닥나는지 → 부족해지면 알려 주기 (3분에 한 번까지, 설정 › 촌장에서 끌 수 있어요).
