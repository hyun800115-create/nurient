## 1. 화면 구성 (세로 화면, 위에서 아래로)

1. **하늘** — 아침 파란 하늘 → 분홍빛 노을 → 별이 가득한 밤. 밤에는 달과 **오로라**가 일렁여요.
2. **로고** (화면 위 약 17%) — 글자가 하나씩 통통 떨어지고, 눈꽃 엠블럼이 빙글 돌며 나타나고,
   「행복한」이 미끄러져 내려오고, 「이야기」 나무 간판이 흔들흔들 매달려요. 다 내려앉으면 반짝! 하고 빛이 훑고 지나갑니다.
3. **먼 풍경** — 구름, 눈 덮인 산 두 겹, 건너편 숲. 도시 단계가 되면 산 너머로 **먼 도시의 불빛**이 켜져요.
4. **바다 위의 섬 (주인공)** — 게임에 실제로 쓰는 그림으로 만든 작은 섬 디오라마.
5. **버튼** — 「터치하여 시작」(아래 약 88%), PC에서는 그 아래 조작 안내, 왼쪽 아래 **버전(v3.5)**,
   오른쪽 위 **톱니바퀴(설정)**.
6. **눈** — 멀리(섬 뒤) 내리는 작은 눈, 앞쪽의 눈송이, 가끔 큼직하게 흐린 눈(보케).

## 2. 섬이 자라는 네 단계

| 단계 | 이름 | 새로 생기는 것 | 소리 |
|---|---|---|---|
| 1 | **개척** | 깃발, 그릴, 판매대, 텐트, 모닥불, 나무 부두와 쪽배, 통나무 더미 · 생선 탑을 든 **촌장**, 모닥불 주위를 뛰는 **콩이** | 뿅 (건물 소리) |
| 2 | **마을** | 통나무집 둘, 오두막, 보트하우스, **망루(횃불)**, 촌장 집, 제재소·빵가마, 흙길, 가로등, 눈사람, 개집 · 마을 사람들, 부두의 낚시꾼, 노 젓는 배, 갈매기 | 뿅뿅 |
| 3 | **읍** | **기차역 + 눈꽃 기차 도착**(다리 건너 칙칙폭폭), 시청, 분수, 타운하우스, 카페·책방·꽃집, 돌길, 가로등 · 말썰매 버스 | 기적 소리 |
| 4 | **도시** | 아파트, 슈퍼, 식당, 버스 정류장, 신호등, 아스팔트 큰길 · **레트로 버스와 자동차**, 항구(크레인·컨테이너·여객선 터미널), **등대 불빛**, 여객선, 요트 | 버스 경적, 뱃고동 |

- 건물은 **화면 가운데부터 바깥으로 물결치듯** 하나씩 "뿅" 하고 튀어나와요 (살짝 찌그러졌다 펴지는 말랑한 느낌 + 눈 뭉치 퐁 + 금별 반짝).
- 텐트는 마을 단계에서 통나무집으로 바뀌고, 제재소와 일부 나무는 읍이 들어설 때 자리를 비켜 줍니다.
- 노을이 지면 집집마다 **창문 불이 하나씩** 켜지고, 가로등 아래 바닥이 따뜻하게 밝아져요. 굴뚝에서는 연기가 모락모락.

## 3. 오프닝 시간표 (처음 켰을 때, 약 11초)

| 시간 | 일어나는 일 |
|---|---|
| 0초 | 하얗게 밝아지며 시작, 캠프 가까이 (아침) |
| 0.35초 | **개척** — 캠프가 생기고 촌장과 콩이 등장 |
| 2.6초 | **마을** — 카메라가 조금 물러나며 마을이 생김 (한낮) |
| 5.0초 | **읍** — 기차가 들어오고 돌길 읍내 (노을) |
| 7.5초 | **도시** — 버스와 자동차, 항구, 등대 (밤, 오로라) |
| 9.9초 | 로고가 글자별로 떨어짐 |
| 10.9초 | 「터치하여 시작」 등장 |

- 화면 아래에 **「개척 › 마을 › 읍 › 도시」** 칩이 있어서 지금 어느 단계인지 한눈에 보여요.
- **아무 때나 한 번 톡** → 바로 마지막 장면(밤의 도시 + 로고)으로 건너뜀. 한 번 더 톡 → 게임 시작.
- 휴대폰 브라우저는 사람이 화면을 한 번 만지기 전까지 소리를 못 냅니다. 그래서 첫 오프닝은 조용하고,
  톡 하는 순간부터 타이틀 음악과 효과음이 나와요.

## 4. 두 번째부터 (진행도에 맞는 타이틀)

- 오프닝 대신 **지금 내 마을의 단계**를 밤 풍경으로 보여 줍니다 (로고가 0.7초 만에 톡 떨어짐).
- 지난번 타이틀 이후 마을이 다음 단계로 자랐다면, 1초 뒤 새 건물들이 뿅뿅 생기며
  **「마을이 자랐어요!」** 리본이 떠요. (한 번만)
- 단계를 정하는 기준 (저장 파일은 **읽기만** 하고 절대 고치지 않아요):

| 단계 | 기준 |
|---|---|
| 개척 | 처음이거나 막 시작 |
| 마을 | 숲 구역을 열었거나, 집·망루·창고 같은 건물을 하나라도 지었거나, v2 마을 완성 |
| 읍 | 기차역을 고쳤거나, 이웃 읍이 열렸거나, v3 마을 완성 |
| 도시 | v5 도시가 생기면 (지금 버전에서는 오프닝에서만 볼 수 있어요) |

## 5. 설정 (톱니바퀴)

효과음 켜기/끄기 · 음악 켜기/끄기 · 언어(한국어/English) · **오프닝: 처음 한 번 / 항상 / 안 보기** ·
**「오프닝 다시 보기」** 버튼 · 닫기.

## 6. 바꾸고 싶을 때 — 어디를 고치면 되나요?

| 바꾸고 싶은 것 | 고칠 곳 |
|---|---|
| **게임 이름** | `src/title/config.js` 의 `TITLE_NAME` 한 곳 → `node tools/title/apply_name.mjs --write` (웹페이지 제목·홈 화면 이름·게임 안 글자까지 한 번에). 3D 로고 그림은 `tools/blender/ttl_config.py` 를 고치고 다시 렌더 |
| 오프닝 시간표 | `config.js` → `TITLE_CFG.intro` |
| 오프닝을 매번/한 번만/안 보기 (기본값) | `config.js` → `TITLE_CFG.introMode` |
| 타이틀의 시간대 (밤/노을/낮) | `config.js` → `TITLE_CFG.idleTime` |
| 로고·하늘·버튼 위치 | `config.js` → `TITLE_LAYOUT` |
| **어떤 건물이 어디에, 몇 단계에** | `src/title/layout.js` 의 `OBJECTS` (`s` = 나타나는 단계, `u` = 사라지는 단계). 고친 뒤 `node tools/title/bake_title.mjs` 로 그림 다시 굽기 |
| 사람·차·배가 다니는 길 | `layout.js` 의 `ACTORS` · `VEHICLES` · `SHIPS` · `TRAIN` |
| 단계마다 카메라 거리 | `layout.js` 의 `CAMERA` (`span` 이 클수록 멀리서 봄) |

## 7. 가볍고 빠르게

- 섬 그림은 미리 구워 둔 작은 그림묶음 4개(단계별)라서, **첫 화면은 캠프 그림(약 200KB)만 있으면 바로** 뜨고
  나머지 단계는 오프닝이 흐르는 동안 뒤에서 받아요. 게임이 원래 받는 그림(캠프 소품, 촌장, 주민)은 다시 받지 않아요.
- 타이틀이 따로 받는 양: 섬 그림 약 1.3MB + 기차·버스·뱃고동 소리 약 0.08MB (로고·하늘 그림은 별도).
- 게임을 시작하면 타이틀에서 쓴 그림 메모리는 **전부 돌려줍니다**.
- '동작 줄이기'를 켠 폰: 오프닝 없이, 움직이지 않는 조용한 타이틀 + 부드러운 페이드만.
