# 마을 말 "눈꽃말" — 우리 마을만의 귀여운 목소리 (대표님 아이디어)

> "마을 사람들 소리가 좀 일본어로 들리는 것 같은데, 우리의 마을 언어 목소리를 만들자.
> 미니언즈처럼 귀여운 목소리 같이 어때?"

## 1. 왜 일본어처럼 들렸나
- 지금 수다 소리는 "자음+모음" 한 덩어리(까, 리, 무…)를 아·이·우·에·오 다섯 모음으로 평평하게 이어 붙여서 일본어 느낌이 났어요.

## 2. 눈꽃말은 이렇게 달라요
- **통통 튀는 소리**: 받침이 있는 소리(뽕, 냠, 꿀), 겹소리(블, 프르), 동글동글한 모음(외·위), 같은 말 두 번(뽀요뽀요)
- **노래하듯 오르내리는 억양**: 질문은 끝이 올라가고, 신나면 빨라지고 높아져요
- **미니언즈처럼 귀엽게**: 목소리를 살짝 높고 빠르게, 웃음·감탄이 많아요 — 하지만 미니언즈 말을 따라 하지 않고 **우리만의 단어**를 만들어요
- **눈꽃말 사전**(예시, 실제 단어는 만들면서 정해요): 안녕 = "뽀야!", 고마워 = "꼬맙뿌", 맛있다 = "냠냠뇨", 뭐야? = "모모?", 와아 = "우와뿅", 촌장님 = "촌촌님", 눈 = "누누", 생선 = "피뽀"

## 3. 목소리 종류
- 아이(남·여), 어른(남·여), 할아버지·할머니, 촌장님, 덩치 큰 아저씨, 상냥한 언니 등 — 주민마다 목소리 높이·빠르기가 조금씩 달라서 같은 사람이면 늘 같은 목소리
- 감정: 인사, 웃음, 놀람, 신남, 슬픔, 투덜, 질문, 고마움, 냠냠, 앗(실수)

## 4. 게임에서
- 말풍선이 뜰 때 그 주민의 목소리로 눈꽃말이 재잘재잘 (글자는 그대로 한국어로 보여요)
- 같은 문장은 늘 같은 눈꽃말로 들려요 (주민 말버릇처럼)
- 여러 명이 동시에 떠들어도 시끄럽지 않게 2명까지만, 멀면 작게
- 설정에서 목소리 크기 조절

## 5. 만드는 순서
- 지금: 눈꽃말 사전 + 목소리 소리 묶음 + 재잘재잘 재생 프로그램 + 들어 볼 수 있는 데모 → 검사관 확인 → 고치기
- 게임에는 다음 버전에 바로 넣어요 (지금 수다 소리를 바꿔요)
