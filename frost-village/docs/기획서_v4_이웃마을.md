# 서리마을 v4 기획 — 이웃 마을과 함께 커지는 마을 (대표님 아이디어 정리)

> 대표님 아이디어:
> "주변에 NPC 마을을 하나 만들어줘. 내가 없는 상점들과 관공서, 학교, 상가, 주택 등. 처음엔 인구 100명 정도.
> 그 마을 사람들이 우리 마을에 물건 사러 오게. 그러면 내 주변으로 마을이 형성되고,
> 내가 생산하는 것을 토대로 주민들이 장사하고 상가와 공장을 세우는 느낌."

## 1. 한 줄 요약
**서리마을(내 마을)이 만드는 물건이 이웃 마을을 먹여 살리고, 그 덕분에 내 마을 주변에 상가·공장·집이 스스로 생겨나며 작은 마을이 도시로 커가는 게임.**

## 2. 이웃 마을 "솔방울 마을" (처음 인구 약 100명)
| 구역 | 건물 |
|---|---|
| 관공서 | 마을회관(촌장 회의), 우체국, 병원, 경찰 초소, 소방서 |
| 교육 | 학교(운동장, 등교·하교), 도서관 |
| 상가 거리 | 카페, 옷가게, 미용실, 꽃집, 서점, 장난감 가게, 식당 (우리 마을엔 없는 가게들) |
| 주택가 | 아파트 2종, 주택 4종, 공원·분수, 놀이터 |
| 교통 | **눈썰매 기차역** — 이웃 마을 사람들이 기차를 타고 **서리마을 역**에 내려 장을 보러 와요 |

- 주민 하루: 집 → 학교/직장 → 점심 → 상가 → **서리마을 장보기** → 집 (낮·저녁·밤 분위기 변화)
- 서리마을 판매대·잡화점·교역소의 손님 대부분이 이웃 마을 사람들 → 생산량이 늘면 손님도 늘어요

## 3. 내 주변으로 마을이 생겨나기 (성장)
내가 어떤 물건을 꾸준히 공급하느냐에 따라 **주민이 가게를 열어요**:
| 내가 공급하는 것 | 생기는 가게·시설 |
|---|---|
| 구운 생선·빵·훈제고기 | 식당, 카페, 도시락 가게 |
| 판자 | 목공소 → 새 집들이 지어짐 (인구 증가) |
| 주괴·도구 | 철물점, 대장간 공방 |
| 통조림 | 슈퍼마켓 |
| (추후) 양모·가죽 | 옷가게, 신발가게 |
| 여러 가지 꾸준히 | 시장 거리, 공장(통조림 2공장 등), 은행 |

- 가게들은 서리마을 주변 빈 땅에 생기고, **우리 물건을 사가서 팔아요** → 우리 수입 + 임대료
- 마을 등급: **마을 → 읍 → 도시** (인구·가게 수·행복도로 올라감), 등급이 오르면 새 건물·새 주민

## 4. 주민 생성기 (NPC를 많이, 다 다르게)
부품을 조합해서 수천 가지 얼굴의 주민을 만들어요:
- 머리 모양 12종 × 머리 길이 3단계 × 머리색 8색
- 피부색 4종, 표정 세트
- 상의 10종 × 색 12색, 하의 6종, 신발
- 모자 10종, 액세서리 (안경, 목도리, 귀마개, 가방, 목걸이, 리본…)
- 직업복: 선생님, 학생 교복, 경찰, 우체부, 의사·간호사, 미용사, 바리스타, 역무원, 공장 노동자…

## 5. 강아지 콩이와 놀기
- 평소엔 마을에서 자유롭게 놀아요 (계속 따라다니지 않음)
- **부르기 버튼(휘파람)** → 콩이가 달려옴
- 다가오면 메뉴: **간식 주기**(냠냠 + 하트), **놀아주기**(공 던지면 물어옴), **쓰다듬기**(배를 보이며 꼬리 흔들기)
- 친밀도 하트 게이지 → 친해지면 특별 반응 (재주 부리기, 선물 물어오기)

## 6. 일꾼 옷과 종류
- 어부: 유치원 우비 느낌 → **두꺼운 니트 스웨터 + 방수 멜빵바지 + 고무장화 + 털모자**, 그물·칼
- 광부: 헬멧+랜턴, 그을린 작업복, 멜빵, 무릎 보호대, 공구 벨트, 볼에 숯검정
- 나무꾼: 체크 셔츠 + 멜빵 + 가죽 장갑 + 털모자 + 작업 부츠
- 농부: 겨울용 누빔 조끼 + 멜빵바지 + 목수건 + 밀짚모자(또는 털모자) + 장갑
- 사냥꾼: 털모자 + 가죽·모피 망토 + 화살통 + 설피(눈신발)
- 직업마다 **2~3가지 모습**(나이·성별·체형 다르게) → 두 번째 일꾼을 고용하면 다른 사람이 와요

## 7. 만드는 순서
1. (지금) v3 코드 + 분업(가공 기술자·재료/상품 짐꾼)
2. (동시에) 그림: 일꾼 옷 새로 + 일꾼 변형, 강아지 놀기 동작, 주민 생성기, 이웃 마을 건물들
3. v4 코드: 이웃 마을 + 기차역 + 주민 일과 + 손님 흐름 + 가게 창업·마을 성장 + 강아지 놀기
4. 검수 → 수정 → 확인 → 테스트 링크

### 8.3 주문판과 새 가게 5곳
주문은 "○○ 보내 주시면 역 앞에 △△을 열게요" 처럼 **어떤 가게가 생길지** 알려 줘요.
물건은 역 앞 **짐 싣는 곳**에 두면 되고, 하나 넣을 때마다 **도매가(판매 가격의 70%)** 를 받아요. 다 채우면 보너스도 있어요.

| 순서 | 생기는 가게 | 주문 | 그 뒤 하는 일 | 임대료 |
|---|---|---|---|---|
| 1 | 역앞 카페 | 빵 30 | 우리 빵을 사다 팔아요 | 1분에 20 |
| 2 | 생선구이 식당 | 생선구이 40 + 훈제고기 15 | 생선구이·훈제고기를 사다 팔아요 | 30 |
| 3 | 목공소 | 판자 50 | 판자로 **집을 지어요** (집 1채 = 이웃 4명) | 25 |
| 4 | 철물점 | 주괴 25 + 도끼 1 + 곡괭이 1 | 도구를 사다 팔아요 | 30 |
| 5 | 슈퍼마켓 | 통조림 20 + 빵 20 | 통조림·빵을 사다 팔아요 | 40 |

- 가게가 물건을 다 팔면 **역 짐꾼**이 우리 물건을 다시 채워 주고, 그때마다 도매가를 받아요.
- 도매가·보너스·임대료는 모두 역 앞 **역 금고**에 모여요 (읍이 되면 저절로 코인으로 들어와요).
- 주문이 3분 동안 안 채워지면 **"다른 주문"** 으로 바꿀 수 있어요. 아직 못 만드는 물건(도구·통조림)의 주문은 나오지 않아요.

### 8.4 솔방울 마을 (주민 100명)
| 구역 | 건물 |
|---|---|
| 역 앞 | 솔방울 역, 역전 파출소, 분수, 놀이터, 썰매 정류장 |
| 상가 거리 (솔방울 큰길) | 카페, 서점, 장난감 가게, 옷가게, 꽃집, 미용실, 식당 |
| 관공서 줄 | 우체국, 학교, 마을회관, 병원, 소방서 |
| 주택가 | 아파트 4동 |

| 주민 | 하루 |
|---|---|
| 학생 18 · 청소년 6 | 8시 종소리에 등교 → 쉬는 시간에 운동장 → 3시 하교, 분수·놀이터로 우르르 |
| 가게 주인 7 | 아침에 가게 앞에 서서 손님맞이, 점심은 식당·카페 |
| 선생님·경찰·우체부·의사·간호사·소방관·촌장 13 | 각자 일터. 우체부는 집집마다, 경찰은 순찰 (밤에도 1명) |
| 어른 36 · 어르신 17 | 동네 가게 돌기 → **기차 타고 서리마을 장보기** → 저녁 7시 귀가 |
| 목수 3 | 가게를 지을 때 기차 타고 와요 |

- 모든 주민은 얼굴·옷·머리가 달라요 (부품 조합). 세 번 넘게 온 손님은 **단골 ★**.
- 휴대폰이 힘들지 않게, 화면 가까이에 있는 사람만 그려요 (최대 32명, 멀리 보면 간단한 모습).

### 8.5 기차
| 무엇 | 값 |
|---|---|
| 모양 | 증기 기관차 + 객차 + 화물차 (읍이 되면 객차 1칸 더) |
| 다니는 길 | 서리역 ↔ 솔방울 역 (해안을 따라 곧게), 약 1분에 한 번 |
| 손님 수 | 기차 1대에 4명 + 가게 1곳마다 +1, 저녁엔 많고 밤엔 적어요 |
| 소리 | 도착 전 기적 소리, 브레이크, 문 여는 소리 |
| 안전 | 촌장이 철길 위에 서 있으면 기차가 멈추고 "기찻길에서 비켜 주세요!" |

기관차는 언제나 우리 마을 쪽 끝에 붙어 있어서, **우리 역에 들어올 때는 기관차가 앞장서요** (솔방울 마을로 갈 때는 뒤에서 밀어요).

### 8.6 마을 등급 마을 → 읍
| 조건 | 필요 |
|---|---|
| 인구 (우리 마을 주민 + 가게 주인 가족 + 새 집 이웃) | 45명 |
| 우리 역 앞 가게 | 5곳 |
| 행복도 (손님이 원하는 걸 다 샀는지) | 70 |
| 승격식 | 14000코인 (3000 이면 조건이 찬 뒤 1~2분 만에 끝나서 올렸어요) |

| 읍이 되면 | |
|---|---|
| 길 | 흙길 → **돌길**, 가로등 |
| 돈 | 역 금고가 저절로 걷혀요 |
| 기차 | 객차 1칸 추가 → 손님 더 많이 |
| 이웃 마을 | 주민 100명 → 120명 (새 이웃 20명이 짐을 들고 와요) |
| 집터 | 새 집터 4곳 |
| 이름 | "읍장" 칭호 + 새 배지 |

도시(3단계)와 버스·트럭·자동차는 v5 예요. 길은 처음부터 **나중에 차가 다닐 수 있게 넓게** 만들어 두었어요 (건물을 옮길 필요 없음).

### 8.8 휴대폰이 버틸 수 있게 (그림 메모리)
- v4 는 **필요한 그림만, 필요한 때만** 올리고, 안 보이는 곳 그림은 내려요. 그림 묶음(아틀라스)을 작은 페이지로 나눠서(`assets/_packed/`) 지금 보이는 동네 것만 올리고, 주민의 이야기 동작은 쓸 때만 불러요. 땅 그림은 화면 둘레만 조각으로 그려요.
- 실제로 잰 그림 메모리 (MB, `tools/test/texbudget.mjs`, 전부 같은 방법으로 잼):

| 장면 | v4 전 (v3.5 방식) | v4 | 약속 (넘으면 안 됨) | 목표 |
|---|---|---|---|---|
| 타이틀 화면 | 88 | 88 | — | 90 |
| 새 게임 | 425 | **191** | 368 | 240 |
| 마을 완성 (v3.5 끝) | 517 | **322** (잠시 뒤 275) | 455 | 300 |
| v4 다 열린 뒤 광장 | 698 | **325** | 455 | 300 |
| v4 가장 무거울 때 (다 열린 직후, 전체 보기) | 719 | **385** | 455 | 300 |

- 게임 엔진이 쓰지도 않는 효과용 그림판을 미리 75MB 만들어 두던 것도 껐어요 (그래픽 카드 메모리 기준 새 게임 299 → 약 227MB).
- **약속(455MB)은 모든 장면에서 지켜요.** 목표는 새 게임(240MB)은 지키지만, 마을이 다 지어진 뒤(275~322MB)와 v4 가 다 열린 뒤(325~385MB)는 목표(300MB)보다 조금 무거워요 (다음에 줄일 곳은 개발 보고서 `docs/build_reports/v4_build.md` 에 적어 두었어요).
- **화면 밖은 그리지 않아요.** 마을·기찻길·솔방울 마을이 다 열리면 한 장면에 그림 묶음이 100개 넘게 섞여서, 휴대폰이 한 번에 못 그리고 여러 번 나눠 그렸어요 (17~22번). 이제 화면에서 멀리 있는 그림은 건너뛰어서 **5~10번**이면 다 그려요 (약속 12번 이하).
- 오래 켜 두면 메모리가 조금씩 늘던 문제(주민 이야기 동작을 내릴 때 동작 정보가 남던 것)를 고쳤어요. 10분 동안 켜 두어도 메모리가 35MB 근처에서 더 늘지 않아요.
- 설정에 **그래픽: 자동 / 선명하게 / 가볍게** 가 있어요. 가볍게는 땅 그림 조각을 덜 만들고, 주민 그림을 더 빨리 내려요.

### 8.9 바다·해변 이야기 (대표님 최신 요청)
- "바닷물도 진짜처럼, 출렁 파도, 해수욕장, 상가·호텔, 해변 사람들" 은 지금 **다른 팀이 따로 만들고 있어요** (물결 그림, 해변 소품, 호텔·가게, 해변 사람, 해변 소리).
- v4 는 바다를 건드리지 않고 **바로 갈아 끼울 자리**만 만들어 두었어요. 해안과 철길 사이도 비워 두었어요.
- **진짜 같은 바다**는 v4 가 끝나면 바로 이어서 넣는 것을 추천해요 (서리마을 앞바다부터). 해수욕장·호텔은 기획서 v7 대로 항구도시(v6)와 함께 들어가요.
