# 기획서: 금방 마켓 (온라인 마켓 + 배달) — v4.3

> 대표님 아이디어: "재고를 빨리 소진하기 위해 온라인 마켓도 만들까? 시민들이 주문하면 물류센터에서 배달차로 시민 집까지!
> 배달 회사는 쿠팡이 아닌 **금방** ㅋㅋ 금방 뭐가 왔지? ㅋㅋ"
>
> → **좋아요. 지금 게임에 딱 필요한 자리예요.** 이 문서는 쉬운 말로 정리한 요약이에요.
> 자세한 설계는 `docs/geumbang_plan.md`, 그림 주문서는 `docs/CONTRACT_GEUMBANG.md` 에 있어요.

---

## 1. 금방이 뭐예요?

| 질문 | 답 |
|---|---|
| 한 줄로 | 마을에 **남는 물건**을 시민이 폰으로 주문하면, **금방 밴**이 집 앞까지 배달해 주는 온라인 마켓이에요. |
| 왜 필요해요? | v4.2 에서 남는 물건(장작·생선·고기·밀·넘친 음식)이 물류창고와 역에 쌓여요. 지금은 걸어오는 솔방울 상인만 사 가서 잘 안 줄어요. 금방이 **재고를 빨리 줄여 줘요.** |
| 어디서? | 새 건물을 짓지 않아요. **서리 물류창고가 그대로 "금방 물류센터"** 가 돼요. 간판 글자만 바뀌고, 닫혀 있던 1번 하역장이 열려요. |
| 언제? | **v4.3** (v4.2 다음). 읍이 되고 물류창고를 지은 뒤예요. 그 전에는 아무것도 바뀌지 않아요. |
| 이름 | **금방** = "곧, 바로". 앱 이름 **금방 마켓**, 배달 회사 **금방물류**, 건물 **금방 물류센터**. |
| 진짜 회사 흉내? | **절대 안 해요.** 쿠팡을 비롯한 실제 회사의 이름·로고·색·마스코트·문구는 하나도 쓰지 않아요 (6장). |

## 2. 어떻게 놀아요? (한 번 배달되는 모습)

| 순서 | 화면에서 보이는 것 | 소리 |
|---|---|---|
| 1. 주문 | 시민 머리 위에 작은 **장바구니 말풍선**. 왼쪽 위 금방 칩 숫자가 +1. | 띵 (앱 알림) |
| 2. 고르기 | 물류센터 지붕을 투명하게 하면, 직원 **쏙쏙이**가 선반에서 물건을 꺼내요. **그 선반이 한 칸 낮아져요** (진짜 재고). | 발소리 |
| 3. 포장 | 컨베이어를 타고 온 물건이 상자에 쏙. **척척이**가 금색 테이프를 **"찌익"**. | 찌익 |
| 4. 싣기 | 상자가 1번 하역장 옆에 쌓이고, **영차**가 금방 밴 뒷문으로 실어요. | 툭, 삑 |
| 5. 배달 | 꿀금색 **금방 밴**이 솔방울 마을 길을 달려요. 모퉁이에서 부드럽게 돌아요 (8방향). 앞에 사람이 있으면 멈춰서 기다려요. | 부릉, 빵빵 (살짝) |
| 6. 문 앞 | 기사님이 상자를 안고 걸어가 **"띵동~ 택배요! 금방이에요!"** | 띵동 |
| 7. 받기 | 주민이 나와서 받고 하트 뿅: **"방금 시켰는데 벌써요? 진짜 금방이네!"** 코인 +18. | 코인 |
| 집에 없으면 | 상자를 **문 앞에 두고 사진**을 찍어요. 오래 두면 상자 위에 **눈이 소복**. 콩이가 와서 킁킁. | 툭 |

- **처음 한 번**은 "첫 주문 따라가기"(약 60초)로 카메라가 상자를 따라가요. 화면을 누르면 바로 끝나요.
- 멀리서 일어나는 배달도 똑같이 끝나요 (코인·후기·문 앞 상자). 안 보인다고 빠지는 건 없어요.
- **서리마을 옛 동네**(차가 못 가는 눈길)는 **허스키 개썰매**가 배달해요. 밴이 역앞 금방 정류장에 상자를 넘겨주면
  썰매 기사 **뽀득이**가 출발해요.

## 3. 언제 열려요? (열리는 순서)

| 언제 | 무슨 일 | 값 |
|---|---|---|
| 약 53분 | (v4.2) 서리 물류창고 완공 | 6,000 + 판자 40 + 주괴 20 |
| 그다음 게임 하루 뒤 (또는 선반이 60 % 넘게 2분) | **정 할머니 편지**: "집 앞까지 갖다 주면 안 될까요?" (소복이가 없으면 알림 + 화살표) | — |
| 편지에서 `금방 시작하기` | 물류창고 문 앞에 **금방 개업** 발판 | **4,000 + 판자 20 + 주괴 10**, 15초 |
| 개업식 | 리본 커팅 → 간판이 **금방 물류센터**로 반짝 → 금색 배너 → 1번 하역장이 열리고 밴이 들어와요 → 직원들이 금방 옷으로 갈아입어요 | — |
| 그 뒤 | 숫자가 필요하다고 할 때만 업그레이드 제안이 하나씩 와요 (5장) | — |

- 옛 저장 파일도 괜찮아요. 물류창고가 있으면 하루 뒤 편지가 오고, "새로워진 것" 카드에 한 줄이 생겨요.
- **개업 전**에는 간판이 지금 잘못 나오던 "솔방울 물류센터" 대신 **"서리 물류창고"** 로 제대로 나와요 (같이 고쳐요).

## 4. 무엇을 팔아요? (가게가 먼저!)

금방은 **물류창고 선반에 남는 물건만** 팔아요. 가게 판매대·식당 창고·광부 식량 상자·마을 창고는 절대 건드리지 않아요.

| 물건 | 가게 값 | **금방 값** | 앱 이름 |
|---|---|---|---|
| 빵 | 7 | 6 | 갓 구운 빵 |
| 훈제 고기 | 12 | 10 | 훈제 고기 한 팩 (판매대가 넉넉할 때만) |
| 구운 생선 | 4 | 3 | 생선구이 |
| 통조림 | 12 | 10 | 통조림 세트 |
| 판자 | 5 | 4 | DIY 판자 |
| 도구 (도끼·낚싯대 등) | 40 | 32 | 새 도끼 … (가끔, 한 번에 하나) |
| 생선 (날것) | — | 2 | 오늘 잡은 생선 |
| 고기 (날것) | — | 5 | 집에서 굽는 생고기 |
| 통나무 | — | 2 | **장작 한 묶음** (겨울 마을은 장작을 때요!) |
| 밀 | — | 2 | 밀 한 자루 |
| 광석·주괴 | — | 안 팔아요 | 집에서 쓸 일이 없어요. 광석은 기차·가공소로 줄여요. |

| 규칙 | 쉬운 말 |
|---|---|
| 가게 먼저 | 어떤 물건의 가게 판매대가 모자라면 그 물건은 **"가게 먼저 · 잠깐 품절"**. 1분 괜찮으면 다시 팔아요. |
| 오늘의 특가 | 선반에 많이 남은 물건은 자동으로 **특가** → 더 많이 주문돼요. 앱에서 무료 **특가 버튼**도 있어요. |
| 바닥 지키기 | 선반에 물건마다 4개는 남겨요. 지붕을 열었을 때 텅 비어 보이지 않게요. |
| 주문하면 바로 빠져요 | 주문이 들어오면 물건이 선반에서 바로 빠져요. 그래서 상인이 같은 물건을 사 가거나, 저장했다 불러와도 사라지는 일이 없어요. |

## 5. 숫자 (처음 값이에요. 봇으로 재서 맞춰요)

| 항목 | 값 |
|---|---|
| 주문하는 집 | 약 60집 (솔방울 아파트·가게 위층·역앞 집 + 옛 동네) |
| 한 집이 주문하는 빈도 | 게임 하루 1.2일에 한 번쯤 (현실 약 12분). 저녁 6–10시에 많고, 눈 오는 날 조금 더 |
| 전체 | 평균 **12초에 1건**, 한 번에 물건 2~6개 (상자 하나) |
| 밴 한 대 | 상자 8개까지, 한 바퀴에 집 6곳까지, 약 2분 반에 한 바퀴 |
| 밴 수 | 처음 1대 → 업그레이드로 최대 3대 |
| 개썰매 | 상자 4개까지 |
| 금방 값 | 가게 값의 **0.8배** (원료는 정해진 값) |
| 버는 돈 | 저녁 시간에 1분에 약 80~120코인, 전체 수입의 **약 +3~5 %** (5 %가 넘으면 값 비율을 낮춰요) |
| 돈이 가는 곳 | 물류창고 앞 **물류 금고** → 딸랑이가 수금 → 은행. 통장에 **금방** 막대가 생겨요 |
| 늦어도 | 벌칙 없어요. 아이가 "오늘은 금방이 아니라 조금방이네~" 하고 웃을 뿐이에요 |

**업그레이드** (필요할 때만 하나씩 제안)

| 업그레이드 | 언제 제안해요 | 값 | 효과 |
|---|---|---|---|
| 포장대 2단 | 포장 기다리는 주문이 6개 넘게 1분 | 1,200 | 고르미 2명 + 포장 1명 더 |
| 금방 밴 2 | 실을 상자가 10개 넘게 90초 | 2,500 | 밴 한 대 더 (부릉이) |
| 금방 밴 3 | 밴 2 다음에 같은 조건 | 4,000 | 밴 한 대 더 (씽씽이) |
| 개썰매 2 | 옛 동네 상자가 6개 넘게 90초 | 1,500 | 썰매 한 팀 더 |
| 광장 / 아파트 금방 보관함 | 썰매 산 뒤 / 밴 2 산 뒤 | 1,800 / 1,500 + 주괴 6 | 한 번에 몰아서 넣고, 주민이 지나가다 찾아가요 ("딸깍! 금방 왔네.") |
| 새벽배송 | 밤에 주문이 8개 넘게 쌓인 날이 3일 | 5,000 | 밤 기사님 2명. 초인종 없이 문 앞에 두고 아침에 "어? 자는 사이에 금방이 다녀갔네!" |
| 돌아오는 길 짐 싣기 | 밴 2대 이상 + 역에 수출 상자가 많을 때 | 800 | 빈 차로 안 돌아오고 역의 남는 상자를 물류창고로 실어 와요 |
| 오늘의 특가 | 언제나 | 무료 | 물건 하나를 하루 동안 주문 2배 |

## 6. 브랜드 (모두 새로 만든 것)

| 항목 | 내용 |
|---|---|
| 슬로건 | **"금방 왔지?"** |
| 부제 | **"방금 시키면 금방 와요"** (방금 ↔ 금방, 글자를 뒤집은 말장난) |
| 대표 농담 | **"금방 뭐가 왔지?" → "금방이 왔지!"** (대표님 아이디어 그대로) |
| 색 | **꿀금색** + **크림색**, 글자에만 조금 **남색** |
| 로고 **금방이** | 금색 동그라미 안에 웃는 얼굴 상자 + 위에 반짝 별. 좌우 대칭이라 밴이 어느 쪽을 봐도 똑같이 보여요. 디자이너가 먼저 시안 3개를 보고 골라요. |
| 마스코트 | 금방이가 짧은 다리로 달리는 모습 + 남색 목도리 (앱에서만) |
| 밴 | 꿀금색 몸통, 크림색 지붕 띠, 옆에 금방이 로고, 지붕 위에 **"금방" 간판** (항상 화면 쪽을 봐서 글자가 거꾸로 보이지 않아요) |
| 직원 옷 | 금색 점퍼 + 남색 모자 (기사님), 금색 조끼 (창고 직원) |

**하지 않는 것**

| 안 써요 | 이유 |
|---|---|
| 쿠팡, 배민, 컬리, 요기요, 쓱, 우체국, CJ대한통운, 한진, 롯데택배, 아마존, DHL, UPS, FedEx 등의 이름 | 실제 회사 |
| 로켓배송, 로켓와우, 샛별배송, 쓱배송, 스마일배송, 쿠팡맨 같은 말 | 실제 회사의 서비스 이름 (택배·새벽배송·문 앞 배송처럼 보통 말은 괜찮아요) |
| 로켓, 날개, 새(제비), 웃는 화살표, 번개, 검은 고양이 모양 | 실제 회사 로고와 비슷해요 |
| 민트색 (배민), 보라색 (컬리), 빨강+주황 (우체국), 파랑 무지개 글자 (쿠팡), 금색+갈색 (UPS), 노랑+빨강 (DHL) | 색 조합이 비슷해요. 그래서 금방은 **금색+크림색** 조합만 써요. |
| 밴 옆면에 글자 | 밴 그림은 반대쪽을 거울처럼 뒤집어 쓰기 때문에 글자가 거꾸로 보여요 |
| 지친 기사님, 혼나는 기사님, 별점 1~3개 후기 | 포근한 게임이에요. 밤 기사님은 따로 있고, 쉬는 모습도 보여요 |

## 8. 금방 앱 (촌장님 폰)

| 탭 | 보이는 것 |
|---|---|
| 오늘 | 주문 · 배달 · **줄어든 재고** · 번 코인, 선반 막대 (어제보다 얼마나 줄었는지) |
| 주문 | 주문 카드마다 **주문 → 고르기 → 포장 → 배달 중 → 도착** 5칸, `따라가기` 누르면 카메라가 그 상자를 따라가요 |
| 상품 | 물건마다 남은 양, 값, 특가 / 판매 중 / 가게 먼저 / 품절, 팔기·쉬기 스위치, 특가 버튼 |
| 기사님 | 밴·썰매가 지금 뭐 하는지, 업그레이드 제안 |
| 후기 | 주민들의 웃긴 별점 후기 |

- 왼쪽 위 **금방 칩** (업무 칩 아래)을 누르면 열려요. 게임은 멈추지 않아요.
